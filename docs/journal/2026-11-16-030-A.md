## 状态与范围

卡 A 代码已实装，自动验证通过；**尚不能标记整卡验收完成**，请求预算例外待 David 答复，浏览器视觉验收被当前工具权限阻断。

仅实现行为 1–10 与 13 的复制部分。上一周期是独立只读数据，不进入当前 `weeks`、undo、autosave、pending revision、reconcile、待核对计数和容量汇总。无卡 B 的放开编辑、更新上一周期、发布确认框或独立撤销；无依赖或后端改动。

- `selectPreviousCycle` 从同学员、开始日更早的非草稿中选最近一份，同开始日按 `published_at` 取较晚值；旧响应缺少该可选字段时以 ID 确定性排序。
- Workspace 当前内容先显示，再读上一周期；generation + effect cancellation 防止旧响应串台。缓存完整树，catalog 改动只重映射，不重复取树；错误可独立重试。
- 复用 `BlockGrid`，默认最后两周；展开数量不存储，折叠按 coach ID 存本机。两区标题及简体、繁体、英文文案齐备。按天排共享星期行的展示坐标，两区存储坐标仍独立。
- 上一周期动作／整天复制走原剪贴板，复制保留逐组设置并清掉服务端 ID、打卡锁。键盘写操作、修改菜单、拖放及填充被隔离；填充与动作拖动的命中限制在所属 grid。
- 显示实际复用现有日志查询；查询日期覆盖上一周期及其提前完成日期。关闭实际且当前无需日志时不新增日志读取。保持当前日志原有依赖刷新条件。
