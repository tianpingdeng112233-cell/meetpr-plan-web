## 实现

既有 AdminWorkspace 新增「教练点评」导航，内部四页：

1. 名录教练：读取 CSV 文本并发送 `{csv}`；展示新建/更新/跳过数及可展开的逻辑行号、跳过原因；按 published/hidden 与姓名/网名/抖音号搜索；完整十四字段编辑；下架/恢复上线。
2. 待审核：展示提交资料与时间，支持通过、拒绝及选填理由。
3. 举报：展示点评原文、每条举报理由/说明、总次数、首次举报至今等待天数/小时；以服务器 `overdue` 决定红色「已超期」。使用点评 ID 执行 keep/delete，明确保留/删除含义，并标明作者已删除的点评不会因保留恢复。
4. 拦截词表：列表、新增与删除。

新增 11 个 API 函数，复用现有 client、JWT、ApiException 处理；响应 `best_total_kg` 与 `coaching_years` 为 `number|string|null`，编辑提交转换为 `number|null`。状态变化后重拉服务端列表；写入有同步 in-flight 防重复点击，失败沿用既有 toast。

复用 Card、CardHeader、PageHeader、FilterChips、SearchBox、Badge、EmptyState、ErrorState、SkeletonRows 和 useResource。未加依赖、未新建视觉体系。文案集中在 `S.admin.coachReviews`，包含英文与生成的繁体。
