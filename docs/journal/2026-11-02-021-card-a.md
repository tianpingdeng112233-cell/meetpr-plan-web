## 卡 B 接线

- `refreshCoachStudents({ include_ended: true })` 请求 `/coach/students?include_ended=1`；无参或 false 保持 `/coach/students`。
- `unbindCoachStudent(id)` 发 POST `/coach/students/:id/unbind`，无 body。
- `setCoachStudentAlias(id, alias)` 发 PATCH `/coach/students/:id`，body `{ alias }`；清除传 `null`。
- `buildStudentRail(students, query)` 返回 `{ active: StudentRailRow[], ended: StudentRailRow[] }`。不修改输入，不读取浏览器存储；折叠状态由界面持有，搜索命中的 ended 行始终返回。
- 每行返回 `student`（原 DTO，含 id/bond_status 等）、`displayName`、`subtitle`（无备注为 null）、`endedAt`（原时间戳或 null）、`pendingVideoCount`（缺失为 0）、`status`。
- `status` 为 `{ key: 'completed', time: 'HH:MM' }`、`{ key: 'scheduled' }`、`{ key: 'rest' }` 或 null（已解绑）。完成文案用 `S.workspace.studentRail.completed(status.time)`，其余用 `S.workspace.studentRail[status.key]`。时间按浏览器本地时区，和总览 `formatTime` 同口径；模型不持有语言状态。
- `today` 缺失或 null 的在训学员按休息组处理；`bond_status` 缺失按在训处理；`alias ?? display_name`，不改本名。
- `previouslyEnded(request)` 返回浏览器本地 `MM/DD`；字段缺失、null 或无效日期返回 null。
- 已解绑分组保留接口相对顺序；零视频计数是否隐藏、分组折叠/搜索展开、请求失败反馈与只读权限接线归卡 B。
