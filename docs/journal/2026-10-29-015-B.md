## ㉓具体接线位置

1. 现有 `NewPlanDialog` 的「从表格导入」tab 仍挂载同一个 `ImportPlanDialog`；没有新增入口或另一套弹窗。
2. `ImportPlanDialog.start()` 在⑮点击「开始识别」、`outlineImport` 成功后，经 `outlineBlocks()` 取得候选。文件有至少两个 block 时 `setStage('blocks')`，渲染㉓；一个 block 或旧响应直接 `setStage('weeks')`，进入⑯。粘贴始终单 block。
3. `latestBlock()` 默认选周日期最新的候选。㉓单选切换调用 `selectBlock()`，更新 `blockId`、该 block 最新连续最多 12 周的默认选择，以及计划名。选中卡片后，「选这个 block，下一步选周」仅将 stage 改为 `weeks`。
4. ⑯列表、连续选择校验、副行均使用当前 `block.weeks`。多 block 的左下为「← 换一个 block」，回到㉓；单 block 仍为「← 换一个表格」，回到⑮。㉓左下也回到⑮。同一次导入换 block 不重发 outline，不额外扣每日次数。
5. 第二步 `recognize()` 继续进入⑰摘要；`cellsFor(index)` 先取该周 `region.sheet` 对应本地页，再按 region 截格。失败周展示、逐格编辑及重试复用同一函数。缺少 `region.sheet` 的旧响应回退到 block 第一页（旧顶层 `sheet`）。
6. 第二步 `header_cells_by_sheet` 从所选 block 的 `header_region_by_sheet` 分页截取，保留 `header_cells` 为该 block 第一页表头；旧响应不添加新字段，保留原请求形状。API 层将新字段写入真实 POST body。
7. 换 block 时清除识别结果、编辑过的 cells、同类写法修正、跳过动作、空周、推断确认、日期/星期选择及创建缓存，避免不同 block 的相同周 index 串用数据。仅从⑯退回㉓、没有换选时保留已有状态。
8. 单 block 计划名沿用本地去扩展名文件名（粘贴「导入计划」）；多 block 为「文件名 · block 名」。文件名仍不发送。`skipped_sheets` 缺失或为空时不渲染灰底说明行。

## 最窄实现选择

- 日期按 block 中最新的非空周日期比较；同日期或全无日期时保留响应顺序中的首个候选。日期范围为最早周起日至最晚周起日加 6 天，⑯与㉓按稿显示 `MM/DD`。
- 某 block 每周训练天数不同则在原定的天数位置显示最小–最大值，不添加控件或额外提示。
- `blocks` 缺失或空数组时按旧顶层字段适配。粘贴若意外收到多 block，使用顶层默认 block，不展示㉓。
- 未发现 CARD-B 与已批准屏幕转写的冲突；未修改产品 spec 或其他正典。
