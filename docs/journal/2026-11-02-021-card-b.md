## 只读机制与状态边界

- `PlanEditor.readOnly` 继续约束原网格、快捷键、保存/发布、历史恢复等路径；已解绑作为额外只读原因，显示专属文案。历史计划仍保留原历史只读文案和行为。
- 解绑成功通过共享 roster 原地切只读，不另建编辑器；解绑前复用原 confirmLeave。已解绑时取消待发远端快照，禁用新建/导入工具，隐藏或禁用写菜单；焦点刷新后此前已打开的写弹窗不再可提交。
- `BlockHistory` 向整日反馈和视频组件传只读；视频播放、历史、已发反馈仍可查看，反馈、标记、校准和画线写入不可用。已解绑不再写视频已看标记。
- 聊天复用原“有效学员集合 / bindLostIds”门禁，conversation ID 与 student ID 分开处理，无会话的已解绑学员也不能发起聊天。
- 花名册 focus、接受申请及本地 mutation 用版本号防旧请求覆盖成功状态；备注保存只合并 alias，解绑只合并绑定状态及日期。
- 后端无 today / bond_status 时沿卡 A 兜底休息组/在训；alias/unbind 失败展示错误，不让页面崩溃。解绑成功后即时日期使用客户端完成时间，后续花名册刷新以服务端 ended_at 为准。
