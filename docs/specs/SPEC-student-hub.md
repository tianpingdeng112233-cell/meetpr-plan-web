- 背景:教练看学员视频有两条互相独立的路径——训练视频 tab(完整工作台:打点/反馈/本组数据)
  与 消息 tab 聊天组卡片弹出的 VideoModal(原生 controls,无打点无反馈)。拍板:合并,
  视频体验只留训练视频那套,VideoModal 删除。

## 目标形态(David 原话锚点:「点击学员后,右侧自动弹出该学员的视频列表,播放器/反馈都用训练视频这套」)

一个 tab 取代现有「消息」+「训练视频」两个 tab:

- **左栏 = 学员列表**(现 MessagesPage 会话列表升级):每行 学员名 + 未读消息数 + 待审视频数
  双徽章;点击选中学员。
- **中栏 = 聊天流**(现 MessagesPage 聊天面板原样搬入):发送/已读回执/轮询/组卡片全保留。
  整列可折叠(复用现有 `column-collapse-toggle` 模式),折叠态记忆(localStorage)。
- **右栏 = 视频区**(现 VideosPage 整体搬入,去掉学员下拉——学员由左栏决定):
  视频列表(按训练日分组 + 全部/待审/已反馈筛选)→ 点视频进入播放器 + 打点(单一档)
  + 给学员的反馈 + 本组数据,全部现有行为不变(键盘 ←/→ 切视频、空格播放、⌘↵ 发反馈)。
- **聊天组卡片点「播放」**:不再弹 VideoModal——右栏视频区定位到该视频并进入播放态;
  若该视频不在当前筛选,自动切「全部」再定位。`VideoModal.tsx` 删除。
- 页面 min-width 1440 不变;三栏同屏放不下播放器大画面时,进入播放态可自动折叠中栏聊天
  (用户手动展开则记住选择)。
