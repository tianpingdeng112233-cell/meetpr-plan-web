## 0. 为什么

教练按月卖线上指导，谁快到期、该谈续费全靠自己记。系统里只有「计划结束日」，但计划可能一个月一换，跟收费周期不是一回事。

## 已拍板（2026-11-04 grill）

| 题 | 决定 |
|---|---|
| 期限从哪来 | 教练给每个学员手填「服务至」日期，与计划无关；不按课次 |
| 谁看得到 | 只有教练（网页端）；学员端、App 教练端都不做 |
| 到期后 | 只提醒，不限制任何功能、不动数据 |
| 在哪显示 | 学员栏 + 总览学员卡常驻；学员资料栏可设置 |
| 老学员 | 没设过不显示、不集中催填；资料栏留入口 |
| 颜色 | 剩 ≤7 天黄色，≤3 天（含今天到期、已过期）红色，红色挂到续期或清除为止 |
| 续期 | 日期选择器 + 「+1 个月」「+3 个月」，从原日期往后算；可清除 |
| 接收新学员 | 网页端接收申请时可选填，可跳过 |
| 解绑 | 期限随这次绑定失效，重新绑定要重填 |
| 叫法 | 「服务至」/「服务剩 N 天」；正典术语「服务期」 |

## 现状事实（已核实）

- 后端没有任何服务期字段；只有计划 `end_date` 与总览的 `plan_ending` 提醒（结束前 3 天到结束后 14 天）。
- 接收申请是 `RequestsPage.tsx` 申请卡片上的一键「接受」，调用 `POST /coach/bind-requests/:id/accept`，没有弹窗。
- 学员栏行模型在 `studentRailModel.ts`，总览学员卡标签在 `overviewBoard.ts`（`OverviewTag`，tone red/yellow/white/gray），学员数据来自 `GET /coach/students`。
- 师生关系 = 一条 accepted 的 `bind_requests` 行；重新绑定会新建一行（057）。

## 术语（写入 `CONTEXT.md`）

- **服务期（service term）**：教练与学员约定的一段收费指导期，只由截止日「服务至」表示，属于某一次绑定。只是提醒，不限制学员任何功能。_Avoid_: 会员期、订阅、合同期、到期日

## 1. 天数口径

- 「服务至 D」表示 D 当天仍在服务期内。
- 剩余天数 N = D − 今天（教练浏览器本地日期，按自然日算）。
- 显示与颜色：

| N | 文案 | 颜色 |
|---|---|---|
| > 7 | 服务剩 N 天 | 灰（`--mut`） |
| 4–7 | 服务剩 N 天 | 黄（`--warn`） |
| 1–3 | 服务剩 N 天 | 红（`--bad`） |
| 0 | 服务今天到期 | 红 |
| < 0 | 服务已过期 \|N\| 天 | 红 |

- 没设服务期 → 不显示任何东西。已解绑学员不显示。

## 2. 设置入口

### 2.1 学员资料栏（右侧）

- 姓名区下方一行「服务至」：
  - 未设置：文字按钮「设置服务期」。
  - 已设置：「服务至 YYYY/MM/DD」+ §1 的倒计时文案（带颜色）+ 「修改」。
- 点开为行内编辑：日期选择器 + 「+1 个月」「+3 个月」+ 「保存」/「取消」+ 「清除服务期」（仅已设置时）。
  - 「+1 个月」「+3 个月」基准：已设置用原「服务至」日期，未设置用今天；按日历月加，月末溢出取该月最后一天（1/31 +1 个月 = 2/28 或 2/29）。点了只改选择器里的值，按「保存」才生效。
  - 允许选过去的日期（补录已过期的学员）。
- 保存失败提示「保存服务期失败，请稍后重试」，保留编辑态。
- 已解绑只读时整行隐藏。

### 2.2 接收新学员

- 申请卡片「接受」按钮旁加选填「服务至」日期输入（带「+1 个月」「+3 个月」，基准今天）。不填直接接受 = 不设服务期。
- 填了则随接受一并提交；接受成功后该学员在学员栏和总览直接带倒计时。

## 3. 显示位置

- **学员栏**：在训学员行，学员显示名**正下方**加一个小号倒计时胶囊（文案省略「服务」二字：「剩 5 天」/「今天到期」/「过期 2 天」，颜色同 §1）；不与右侧完成时间、视频角标排在一行（David 定稿时指定）。灰色档（>7 天）也显示。有备注时显示名下方已有本名小字，胶囊排在本名小字之下。
- **总览学员卡**：标签行加一个服务期标签，文案用 §1 全称，tone 映射：灰档 → `gray`，黄档 → `yellow`，红档 → `red`。红色服务期标签与其他红色标签同等对待（计入「需关注」分组与红色计数）；黄、灰同其他同色标签。
- 资料栏：见 §2.1。
- ⌘K、顶栏、编辑网格不显示。

## 4. 文案三语

| key | 简体 | 繁体 | English |
|---|---|---|---|
| 设置 | 设置服务期 | 設定服務期 | Set coaching term |
| 标签 | 服务至 | 服務至 | Coaching until |
| 剩 N 天 | 服务剩 N 天 | 服務剩 N 天 | N days left |
| 今天到期 | 服务今天到期 | 服務今天到期 | Ends today |
| 已过期 | 服务已过期 N 天 | 服務已過期 N 天 | Ended N days ago |
| 清除 | 清除服务期 | 清除服務期 | Clear term |
| 失败 | 保存服务期失败，请稍后重试 | 儲存服務期失敗，請稍後重試 | Couldn't save the term. Try again later. |
| 接收卡提示 | 服务时限可在学员资料栏随时修改。 | 服務時限可在學員資料欄隨時修改。 | You can change the term anytime in the student panel. |
| 选填标签 | 服务至（选填） | 服務至（選填） | Coaching until (optional) |

学员栏胶囊的短文案同理（剩 N 天 / 今天到期 / 过期 N 天；繁体、英文 `N d left` / `Ends today` / `Ended N d ago`）。

## 验收清单

1. 资料栏：未设置显示「设置服务期」；设置、修改、清除都生效，刷新后保持；「+1/+3 个月」按 §2.1 基准与月末规则；可选过去日期。
2. §1 五档在边界值上文案与颜色正确：N = 8、7、4、3、1、0、−1（用 staging 造号或改日期验证）。
3. 学员栏胶囊与总览标签在同一学员上天数一致；红色服务期标签把学员归入「需关注」并计入红色计数。
4. 接收申请：不填直接接受 → 无倒计时；填了接受 → 学员栏与总览立刻带倒计时。
5. 解绑后该学员不显示服务期；用邀请码重新绑定并接受（不填）→ 无倒计时（旧期限不回来）。
6. 带历史的老教练账号（20+ 学员、全部没设服务期）升级后第一屏：学员栏、总览与升级前一致，没有空胶囊、没有催填提示。
7. 繁体、英文界面三处文案正确。
8. 本地全量测试 + `tsc --noEmit` + build 全绿；Opus 浏览器亲验以上各项。

## Out of Scope

- 学员端（iOS / 安卓）显示服务期；App 教练端显示或设置。
- 推送、邮件、站内信等到期通知；每日摘要。
- 按课次计数、收款记录、续费历史。
- 到期自动限制、自动解绑。
- 批量设置服务期；上线后催老学员补填。

### ① 编辑器学员栏 + 资料栏只读态
- **学员栏行**（最小高 48，上下内边距 6）：左列为竖排——显示名（14px）；（有备注时）本名小字；服务期胶囊（11px，行高 16，左右内边距 6，圆角 8，左对齐）。右侧同一行依次：状态文字（「HH:MM 完成」等，12px）、待看视频红色角标。没设服务期的学员没有胶囊，行高回到原样。
- **资料栏**：姓名行（姓名 + 「修改学员备注」）下方是一块浅描边卡片（内边距 12，圆角 8）：
  - 第一行左「服务至 YYYY/MM/DD」（标签灰色 13px，日期深色加粗），右侧文字链「修改」。
  - 第二行左对齐胶囊，全称文案（「服务剩 3 天」等，12px，行高 20，圆角 10），颜色按 §1。
  - 卡片下面是现有资料内容，再下是「解绑」按钮，都不变。

### ② 资料栏编辑态
- 点「修改」或「设置服务期」后，卡片换成编辑态（描边加深为 `--tint-bd` 一档、浅底）：
  - 标签「服务至」+ 原生日期输入（高 36，整宽）。
  - 一行两个圆角胶囊按钮「+1 个月」「+3 个月」（高 32）。
  - 一行 12px 灰字说明基准：已设置时「从原日期 YYYY/MM/DD 往后算」，未设置时「从今天往后算」。
  - 底行：左侧红色文字链「清除服务期」（仅已设置时显示），右侧「取消」（次要按钮）、「保存」（主色按钮），高 32。
- 未设置时只读态卡片里只有一个文字按钮「设置服务期」。

### ③ 总览学员卡
- 服务期标签与其他标签同一行、同尺寸（12px，行高 24，圆角 12），排在标签行**最前**；文案用全称。
- 与其他同色标签区分：服务期标签多一圈 1px 同色内描边。
- 红色服务期标签的学员出现在「需关注」分组（稿中三例：剩 3 天、已过期 2 天、今天到期）；黄色、灰色留在「其他」。

### ④ 接收申请卡片
- 申请卡片（姓名 + 自报信息）下加分隔线，其下一行从左到右：「服务至（选填）」标签 + 日期输入（宽 180，高 36）、「+1 个月」「+3 个月」（基准今天）、弹性空白、「拒绝」、「接受」。窄屏时整行换行。
- 卡片底部 12px 灰字：「服务时限可在学员资料栏随时修改。」（David 定稿时改的文案，照抄）。
