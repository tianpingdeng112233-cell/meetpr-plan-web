- **产品正典**: `meetpr-rn` / `MeetPR` 仓 `specs/107-all-day-sheet/SPEC.md`（学员端训练页「全天一览」）；后端 `MeetPR-backend` `specs/065-all-day-sheet/SPEC.md`。本文件只定教练网页。
- **级别 / 节奏**: T1（网页单模块展示改动，依赖后端 065 接口），P1。与 065、107 **同一批上线**。

## 已拍板（不重议）

1. 学员的「问教练」改为动作级留言：教练收到的是「动作 + 学员输入的文字」。
2. 网页上看到这条留言时，**鼠标悬停**在计划表格里高亮对应的动作（David 原话）；点击滚动定位过去（David 8A）。
3. 学员可以不填重量就完成训练，组重量为空；所有显示处为「—」。
4. 组实际值与处方一致时，教练端显示「按计划」（不新增存储字段，前端比对得出）。

## 变更

### 1. 动作留言卡片

- 消息带 `exercise_ref`（后端 065 §2）时，在聊天里渲染为卡片：上行「11/10 · 暂停卧推」（日期 M/D + 动作名，小号次要色），下行学员原文（正文去掉服务端首行 `[动作留言] …`）。
- 出现位置：编辑器内聊天 `src/features/chat/EditorChat.tsx` 与消息页 `MessagesPage.tsx`；会话列表预览照常显示正文首行。
- 旧的按组 `set_ref` 卡片渲染不变。

### 2. 悬停高亮与点击定位

- 编辑器内聊天里，鼠标悬停动作留言卡片 → 计划表格中对应的计划动作（按 `plan_exercise_id`）整块高亮（复用编辑器现有选中 / 强调样式，浅色模式，参照 `web-light-only-editor-palette` 配色）；移开取消。
- 点击卡片 → 切到该日所在的周 / 列并滚动到该动作，短暂闪烁高亮后保持选中。
- `plan_exercise_id` 为空（自加动作）或该动作已被教练删除：悬停不高亮；点击定位到 `plan_day_id` 那一天；那天也不存在时卡片右侧显示「原动作已不在计划中」，不报错。
- 在消息页（不在编辑器里）点击卡片 → 打开该学员的计划编辑器并定位，同上。

### 3. 空重量与「按计划」

- 所有显示学员实际组重量的地方（`BlockHistory`、`ContextRail`、`workspace/StatsViews`、`WorkspaceCommon`、聊天 `setRef`）：`weight_kg` 为 `null` 显示「—」，统计 / 合计跳过该组，不出现 NaN 或 0。
- 实际重量、次数、RPE 与处方完全一致（区间处方落在区间内）时，实际值位置显示「按计划」小标签；任一项不一致照常显示实际值（沿用现有差异样式）。
- 请求头加 `X-MeetPR-Caps: set-weight-nullable`（后端 065 §1），否则拿到的是兼容用的 `"0"`。


## 走查第 2 轮修订（David 2026-11-11，优先于前文）

- 取消「按计划」小标签：实际值与处方一致时也照常显示实际值（与处方并排的现有样式不变），不加任何标签。删除 `actualMatchesPlan` 及其显示接线与测试。
- 动作留言卡片的标签文案为「学员留言」：「11/10 · 暂停卧推 · 学员留言」+ 原文。

## 验收清单

1. 学员发一条动作留言：编辑器聊天与消息页都显示「日期 · 动作」卡片 + 原文；旧 `set_ref` 卡片照常。
2. 悬停卡片 → 对应动作高亮，移开取消；点击 → 定位到那一天那一个动作。
3. 自加动作留言、被删动作留言：悬停不报错，点击退化为定位到那一天或显示「原动作已不在计划中」。
4. 有空重量组的学员：所有实际值处显示「—」，统计不出 NaN / 0。
5. 学员不改值直接完成的一天：实际值处显示「按计划」；改过的组显示实际值。
6. 请求头已带 caps；本地对着后端 065 契约样例 `specs/065-all-day-sheet/contract-samples.json` 跑通。
