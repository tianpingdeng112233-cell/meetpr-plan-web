## 0. 为什么

走查看到的教练写法：一份计划就是一个 block（通常 4 周）；**按周写**，W1 整周写完再写 W2；主项变式和辅助项在 4 周之间基本是复制粘贴，变的是数字。写的时候要一直看到：整个 block、同一 Dx 跨周怎么递进、这个动作过往的顶组与分组、视频。

现网格对不上：一周一条竖带、一屏只放得下约 1 周；历史只在填某一行时出现在日头里，行填完就收起；编辑器里看不了视频；按钮多、一眼看过去乱。

## 术语（已写入 `CONTEXT.md`）

- **Block**：一份计划本身，3–6 周（默认 4），教练按周推进数字、动作基本不变。
- **Dx（第 x 练）**：一周里的第 x 个训练日，按日期先后排；同一个 Dx 在各周落在同一列。
- **速记**：扫视态里一个动作的一行写法，`动作名 组×次 @强度 重量`。
- **向下填充**：把某周某个 Dx 的一行或整天，复制到后面各周的同一个 Dx。

## 1. 主骨架

```
            D1 · 周一      D2 · 周三      D3 · 周五      D4 · 周六        │ 历史栏
W1 10/20    [一天]         [一天]         [一天]         [一天]           │
W2 10/27    [一天]         …                                              │
W3 11/03                                                                  │
W4 11/10                                                                  │
```

- **行 = 周**（W1…Wn，自上而下），**列 = Dx**（D1…Dk，k = 该计划各周训练日数的最大值）。同一 Dx 跨周在同一列，上下对齐即可比较。
- 行头是窄条（约 48px）小字：周号、该周起始日期，本周标「本周」。容量摘要（主项组数 · 辅助组数 · 总量，沿用现 `WeekCapacitySummary` 的数据）只在悬停行头时显示。（2026-10-19 David 看稿后改：周标不占大空间。）
- 列头：`Dx · 星期几`（见 §5）。
- 格子 = 一天，**扫视态**：主项及变式在上、辅助项在下，中间一道细分隔；每个动作一行速记，做成一块可选中的积木（见 §4.2）。没排的格子留白，悬停出「＋」。已打卡的动作在速记后带完成标记，详情（实际值、学员自加，spec 010）只在编辑态显示。
- 尺寸目标：1440×900、历史栏展开时，4 周 × 4 Dx 一屏放下不需要滚动；周数更多时整页上下滚动（不翻页、不分段）；Dx 多于 4 列时横向滚动。
- 一次只有一个格子处于编辑态。

## 2. 编辑态

- 点格子 → 该格**原位展开**为这一天的完整编辑（字段与今天相同：动作 / 组 / 次 / 强度方式与值 / 重量方式与值 / 备注；主项与辅助分节、加动作、拖拽排序、已打卡锁定、实际值与学员自加显示全部沿用）。该周这一行**按编辑卡内容撑高，任何情况下不裁切、不溢出到下一周**（其他周的行保持速记高度，整页放不下时上下滚动，并把编辑卡滚到可见）；**同一列其他周保持速记**，所以写 W2D1 时正上方就是 W1D1。
- 强度方式、重量方式的下拉只在编辑态出现。
- 退出：Esc、点格子外、或点另一个格子（切过去）。退出时不丢输入（自动保存逻辑不变）。
- 编辑卡头部只有「W2 · D3 硬拉日」+ 日期文字「周五 10/31」+「Esc 收起」，**没有「⋯」菜单、没有其他按钮**（2026-10-19 David 看稿后删）。日期是文字，点它才弹出日期选择；不要常驻原生日期输入框。编辑卡里**不放**学员画像 / 上下文块（历史与画像都在右侧历史栏，卡 B）。
- 编辑卡每行单行、高约 38–40px：强度「方式 ▾ + 值」、重量「方式 ▾ + 值」都在同一行内，不上下堆叠。
- 编辑态里**每个动作行也是一块积木**：拖框选中几行、`Cmd/Ctrl + C` 复制、到别的格子 `Cmd/Ctrl + V` 粘贴、`Delete` 删除，与扫视态一致（§4.2）；卡片底部一行小字提示这几个手势。
- **每一行都有备注输入框**（主项、辅助项一样），空时显示占位「备注」。
- 原「选中条」上的动作改为手势：复制上周 = 选中上周那格 `Cmd/Ctrl + C`、点本周 `Cmd/Ctrl + V`；清空本日 = 选中格子或全部积木按 `Delete`（可撤销）；粘贴动作 = `Cmd/Ctrl + V`。右键菜单保留「复制 / 粘贴 / 清空本日」三项作兜底。

## 3. 历史栏（右侧常驻）

### 3.1 位置与行为
- 固定在页面右侧，宽约 280px，**不再自动收起**；可手动收起成窄条，收起状态记在本机（沿用 `RAIL_MODE_KEY` 的做法）。
- 现在日头里的学员画像与 e1RM 概览移到历史栏的第 0 级（见下）。日头不再变成深色上下文块。

### 3.2 逐级收窄（跟随编辑态里当前光标所在的行）
| 级 | 条件 | 显示 |
|---|---|---|
| 0 | 没有选中动作行 | 学员画像摘要 + 三项 e1RM（沿用现第 1 级内容） |
| 1 | 行已绑定动作 | **该动作近 5 次**训练 |
| 2 | 再填了组数 N | **该动作 × N 组**的近 5 次 |
| 3 | 再填了次数 M | **该动作 × N 组 × M 次**的近 5 次 |

- 级别随输入即时变化；删掉次数就回到第 2 级。
- 每级顶部一行小标题说明当前口径，例如「相扑硬拉 · 4 组 × 3 次 · 近 5 次」。
- 没有记录：「暂无 4×3 的记录」，并给一个回到上一级的文字链。

### 3.3 一条记录长什么样
一条一行：`10/16 · 4×3 · 顶组 210×3 @8 ▶`。展开（点这一行）看各组明细：`210×3 @8 ✓ / 190×3 @7 / 190×3 @7.5 / 190×3 @8`，失败组、未完成组沿用现有样式。顶组 = 当次重量最大的一组（并列取组序靠前）。
- 有视频的组带 ▶；点 ▶ 后播放器**固定在历史栏顶部**播放（复用视频页的播放组件：倍速、逐帧），记录列表顺延到下面；可关闭，不离开编辑器、不打断编辑态，不做浮动小窗。（2026-10-19 David 看稿后改。）

### 3.4 数据与降级
- 第 1 级：现有 `GET /coach/students/:id/exercise-stats?exercise_id=` 的 `recent_sessions`（后端已是 5 次）。
- 第 2、3 级：后端 051 新增的 `sets` / `reps` 查询参数与 `filtered_sessions`。
- 视频：后端 051 在每组上补 `video_id`；播放取 `GET /uploads/:id/url`（现有）。
- **旧后端**（响应里没有 `filtered_sessions`、组上没有 `video_id`）：第 2、3 级退回第 1 级的列表并在小标题旁注明「按组次筛选需更新后端」；▶ 改为跳视频页（今天的行为）。不报错。
- 同一动作 / 组 / 次的查询结果在本页会话内缓存，切行不重复请求；保存或发布后不需要刷新历史。

## 4. 复制：拖右下角 + 框选行 ⌘C / ⌘V

（2026-10-19 David 看稿后定：不要「向下填充」按钮，也不要 ⌘D；复制只有下面两种手势。）

### 4.1 整天：拖右下角（向下填充）
- 选中一个格子（扫视态单击）后，右下角出现填充柄；鼠标移到格子上时填充柄放大，旁边提示「拖动复制到下面几周」。
- 按住填充柄往下拉，拉到哪一周就复制到哪一周的同一 Dx，拉动时目标格显示虚线预览，松手生效。
- 覆盖目标天；目标天非空时先确认（沿用多选粘贴的确认文案与逻辑）。

### 4.2 几行：框选积木，⌘C / ⌘V
- 扫视态里每个动作行是一块**积木**（一行速记、圆角浅灰底），单击选中一块，Shift / Cmd 点选加选，**按住鼠标在格子里拖框**可框选多块；选中的积木为淡黄底、深色描边。框跨到别的格子就变成选整天（多天），与现在的多选天一致。
- `Cmd/Ctrl + C` 复制选中的积木，点目标格 `Cmd/Ctrl + V` 粘贴：追加到目标天对应分节（主项 / 辅助）末尾，已有同一动作也照样追加，不合并。
- **整天的复制粘贴保持 Excel 习惯**：选中格子（或多选几天）`Cmd/Ctrl + C`，点目标格 `Cmd/Ctrl + V`，即现有多选天复制粘贴的行为。

### 4.3 共同规则
- 目标天里已打卡（锁定）的动作不动；目标周超出计划结束的部分跳过；目标周该 Dx 不存在（那周训练日少）时，按 §5 的星期规则新建这一天。
- 复制完各周**完全独立**，之后改 W1 不影响 W2–W4。
- 一次拖动或一次粘贴 = 一步撤销。
- 「复制上周」不再有按钮，用整格 `Cmd/Ctrl + C / V` 完成。
- 「不要 ⌘D」只指不用 ⌘D 做跨周复制。**原有的 ⌘D（在一行里把强度 / 重量逐组向下填充）照旧保留**，它是已上线功能。

## 5. Dx 与日期

- **星期规律**：一份计划有一套「Dx → 星期几」的规律（例如 D1=周一、D2=周三、D3=周五、D4=周六），显示在列头。新建计划时与第一练日期、周数一起设（见 §6）；之后点列头可改，改动作用于**各周尚未打卡**的那个 Dx，已打卡的日子日期不动。
- 每周的日期由第一练日期 + 规律自动排出。某一周要例外（这周 D2 挪到周四），在编辑态改那一格的日期即可，只影响这一格；格子右上角显示它自己的日期。单格改日期**只能改到本周 7 天里空着的日子**（不跨周、不和已有训练日互换）；已后移的日子不提供单独「恢复原日期」，用后移的撤销。（2026-10-19 收货时定。）
- **格子按星期落列**：列头星期已知时，每周的训练日按它的星期放进对应的 Dx 列（例：W4 减量周没有周三，周五仍在 D3 列，D2 那格留空「＋」）；只有星期对不上任何列的日子（存量不规律计划）才按当周日期先后顺位补位。
- 后移（spec 045）照常可用，后移过的格子显示「已后移」与新日期。
- **存量计划**：不强行套规律。Dx = 当周按日期排的第 x 个训练日；列头星期取该列最常见的星期；与列头不同的格子显示自己的日期。打开计划不改任何数据。

- 顶栏常驻只有：图标 · 学员▾ · 计划▾ · 保存状态 · 待核对芯片（数量 > 0 才出现）· 发布给学员 / 更新计划。
- 收进「计划▾」菜单：新建计划、重命名、计划设置（第一练日期 / 周数 / 星期规律）、导入 .xlsx、补录过往训练、标记完成、删除草稿。
- 从页面上去掉：周期化条（MESOCYCLE）、周标签行与翻周按钮、选中条、公式栏、「加一周」按钮（周数在计划设置里改）。

- 一周 = 从 D1 那天算起的 7 天：计划的 `start_date` 就是第一练日期，现计划树按 `start_date` 偏移 0–6 天的模型不用改。

## Out of Scope

- 待写计划提醒（教练现在用日历记）——学员看板已有「待排」，另开题。

- 「一行贯穿全周」式的共享动作行；各周保持独立。
- 修改计划树 / 快照的数据模型；任何学员端（iOS / 安卓）改动。
- 窄屏适配：低于 1280 宽只保证不崩、可横向滚动。
- 新的统计口径或追踪看板改动。
