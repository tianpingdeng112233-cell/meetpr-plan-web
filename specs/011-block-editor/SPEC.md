## 0. 为什么

走查看到的教练写法：一份计划就是一个 block（通常 4 周）；**按周写**，W1 整周写完再写 W2；主项变式和辅助项在 4 周之间基本是复制粘贴，变的是数字。写的时候要一直看到：整个 block、同一 Dx 跨周怎么递进、这个动作过往的顶组与分组、视频。

现网格对不上：一周一条竖带、一屏只放得下约 1 周；历史只在填某一行时出现在日头里，行填完就收起；编辑器里看不了视频；按钮多、一眼看过去乱。

## 术语（已写入 `CONTEXT.md`）

- **Block**：一份计划本身，3–6 周（默认 4），教练按周推进数字、动作基本不变。
- **Dx（第 x 练）**：一周里的第 x 个训练日，按日期先后排；同一个 Dx 在各周落在同一列。
- **速记**：扫视态里一个动作的一行写法，`动作名 组×次 @强度 重量`。
- **向下填充**：把某周某个 Dx 的一行或整天，复制到后面各周的同一个 Dx。

## 1. 主骨架

```
            D1 · 周一      D2 · 周三      D3 · 周五      D4 · 周六        │ 历史栏
W1 10/20    [一天]         [一天]         [一天]         [一天]           │
W2 10/27    [一天]         …                                              │
W3 11/03                                                                  │
W4 11/10                                                                  │
```

- **行 = 周**（W1…Wn，自上而下），**列 = Dx**（D1…Dk，k = 该计划各周训练日数的最大值）。同一 Dx 跨周在同一列，上下对齐即可比较。
- 行头：周号、该周起始日期、容量摘要（主项组数 · 辅助组数 · 总量，沿用现 `WeekCapacitySummary` 的数据与悬停明细）。
- 列头：`Dx · 星期几`（见 §5）。
- 格子 = 一天，**扫视态**：主项及变式在上、辅助项在下，中间一道细分隔；每个动作一行速记。没排的格子留白，悬停出「＋」。已打卡的动作在速记后带完成标记，详情（实际值、学员自加，spec 010）只在编辑态显示。
- 尺寸目标：1440×900、历史栏展开时，4 周 × 4 Dx 一屏放下不需要滚动；周数更多时整页上下滚动（不翻页、不分段）；Dx 多于 4 列时横向滚动。
- 一次只有一个格子处于编辑态。

## 2. 编辑态

- 点格子 → 该格**原位展开**为这一天的完整编辑（字段与今天相同：动作 / 组 / 次 / 强度方式与值 / 重量方式与值 / 备注；主项与辅助分节、加动作、拖拽排序、已打卡锁定、实际值与学员自加显示全部沿用）。该周这一行随之变高；**同一列其他周保持速记**，所以写 W2D1 时正上方就是 W1D1。
- 强度方式、重量方式的下拉只在编辑态出现。
- 退出：Esc、点格子外、或点另一个格子（切过去）。退出时不丢输入（自动保存逻辑不变）。
- 原「选中条」上的动作（复制上周、粘贴动作、清空本日）改放在编辑态格子的「⋯」菜单与右键菜单里；快捷键照旧。

## 3. 历史栏（右侧常驻）

### 3.1 位置与行为
- 固定在页面右侧，宽约 280px，**不再自动收起**；可手动收起成窄条，收起状态记在本机（沿用 `RAIL_MODE_KEY` 的做法）。
- 现在日头里的学员画像与 e1RM 概览移到历史栏的第 0 级（见下）。日头不再变成深色上下文块。

### 3.2 逐级收窄（跟随编辑态里当前光标所在的行）
| 级 | 条件 | 显示 |
|---|---|---|
| 0 | 没有选中动作行 | 学员画像摘要 + 三项 e1RM（沿用现第 1 级内容） |
| 1 | 行已绑定动作 | **该动作近 5 次**训练 |
| 2 | 再填了组数 N | **该动作 × N 组**的近 5 次 |
| 3 | 再填了次数 M | **该动作 × N 组 × M 次**的近 5 次 |

- 级别随输入即时变化；删掉次数就回到第 2 级。
- 每级顶部一行小标题说明当前口径，例如「相扑硬拉 · 4 组 × 3 次 · 近 5 次」。
- 没有记录：「暂无 4×3 的记录」，并给一个回到上一级的文字链。

### 3.3 一条记录长什么样
一条一行：`10/16 · 4×3 · 顶组 210×3 @8 ▶`。展开（点这一行）看各组明细：`210×3 @8 ✓ / 190×3 @7 / 190×3 @7.5 / 190×3 @8`，失败组、未完成组沿用现有样式。顶组 = 当次重量最大的一组（并列取组序靠前）。
- 有视频的组带 ▶；点 ▶ 在页面里弹出**小窗播放器**（复用视频页的播放组件：倍速、逐帧），可拖动、可关闭，不离开编辑器、不打断编辑态。

### 3.4 数据与降级
- 第 1 级：现有 `GET /coach/students/:id/exercise-stats?exercise_id=` 的 `recent_sessions`（后端已是 5 次）。
- 第 2、3 级：后端 051 新增的 `sets` / `reps` 查询参数与 `filtered_sessions`。
- 视频：后端 051 在每组上补 `video_id`；播放取 `GET /uploads/:id/url`（现有）。
- **旧后端**（响应里没有 `filtered_sessions`、组上没有 `video_id`）：第 2、3 级退回第 1 级的列表并在小标题旁注明「按组次筛选需更新后端」；▶ 改为跳视频页（今天的行为）。不报错。
- 同一动作 / 组 / 次的查询结果在本页会话内缓存，切行不重复请求；保存或发布后不需要刷新历史。

## 4. 向下填充

- **对象**：编辑态里选中的一行或多行；或整天（在格子「⋯」里选「整天」，或选中格子未进入编辑时）。
- **操作**：
  - 拖动格子右下角的填充柄往下拉，覆盖到哪一周就填到哪一周（同一 Dx 列）；
  - 快捷键 `Cmd/Ctrl + D`：填到下一周的同一 Dx；连按继续往下。
- **规则**：
  - 填行：追加到目标天对应分节（主项 / 辅助）末尾；目标天里已有同一动作也照样追加，不合并。
  - 填整天：覆盖目标天；目标天非空时先确认（沿用多选粘贴的确认文案与逻辑）。
  - 目标天里已打卡（锁定）的动作不动；目标周超出计划结束的部分跳过；目标周该 Dx 不存在（那周训练日少）时，按 §5 的星期规则新建这一天。
  - 填完各周**完全独立**，之后改 W1 不影响 W2–W4。
  - 一次填充 = 一步撤销。
- 现有的多选天 `Cmd/Ctrl+C / V`、单行复制粘贴、「复制上周」全部保留。

## 5. Dx 与日期

- **星期规律**：一份计划有一套「Dx → 星期几」的规律（例如 D1=周一、D2=周三、D3=周五、D4=周六），显示在列头。新建计划时与开始日期、周数一起设（见 §6）；之后点列头可改，改动作用于**各周尚未打卡**的那个 Dx，已打卡的日子日期不动。
- 每周的日期由开始日期 + 规律自动排出。某一周要例外（这周 D2 挪到周四），在编辑态改那一格的日期即可，只影响这一格；格子右上角显示它自己的日期。
- 后移（spec 045）照常可用，后移过的格子显示「已后移」与新日期。
- **存量计划**：不强行套规律。Dx = 当周按日期排的第 x 个训练日；列头星期取该列最常见的星期；与列头不同的格子显示自己的日期。打开计划不改任何数据。

## 6. 顶栏精简与品牌

- 左上角放 **MeetPR app 图标**（iOS `MeetPR/Assets.xcassets/AppIcon.appiconset/meetpr-icon-1024.png` 的浅色版，金色圆章），旁边是「MeetPR」字样；浏览器标签页图标也换成它。
- 顶栏常驻只有：图标 · 学员▾ · 计划▾ · 保存状态 · 待核对芯片（数量 > 0 才出现）· 发布给学员 / 更新计划。
- 收进「计划▾」菜单：新建计划、重命名、开始日期 / 周数 / 星期规律、导入 .xlsx、补录过往训练、标记完成、删除草稿。
- 从页面上去掉：周期化条（MESOCYCLE）、周标签行与翻周按钮、选中条、公式栏、「加一周」按钮（周数在计划设置里改）。
- 新建计划对话框：开始日期、周数（3–6，默认 4；导入与存量计划不受此限）、每周训练日的星期。

## 7. 存量计划与功能保全（交付红线）

- **不改数据模型**：计划树、快照（pending revision）、远端草稿镜像、发布 / 更新的请求体与 reconcile 全部不变。改的只有前端的排布与交互。
- 任何存量计划在新页里都必须完整打开、可查、可改，包括：超过 6 周的（最多 12 周，上下滚动）、xlsx 导入的、已发布且有打卡的、有学员自加记录的（spec 010）、后移过的、历史只读的、每周训练日数不一样的、星期不规律的。
- 旧编辑页直接被替换，不留入口。下列现有能力在新页里必须都在（UI 卡逐项进验收）：草稿自动保存与失败提示、发布 / 更新与送达确认、已发布计划远端镜像与冲突提示、更新失败重试弹窗、后移与撤销、多选天复制 / 粘贴 / 清空、单行复制粘贴、复制上周、天内拖拽排序、已打卡锁定与实际值、学员自加显示、周容量摘要、待核对芯片与逐个定位、自定义动作、拼音搜索、键盘导航、导入 xlsx、中英文、学员与计划切换、重命名学员、补录过往训练、标记完成、删除草稿。

## 验收清单

1. 1440×900、历史栏展开：一份 4 周 × 4 练的计划一屏完整可见，不滚动；同一 Dx 跨周上下对齐。
2. 点 W2D1 → 原位展开编辑，W1D1、W3D1、W4D1 仍为速记；Esc 退出不丢输入。
3. 历史栏常驻：填完一行不收起；在编辑态里选中「相扑硬拉」行看到近 5 次；填组数 4 → 小标题变「4 组」、列表只剩 4 组的记录；再填次数 3 → 只剩 4×3 的；删掉次数回到「4 组」。
4. 有视频的组点 ▶ → 页内小窗播放，编辑态不退出；关小窗后光标还在原格。
5. 旧后端（无 051）：第 2、3 级退回第 1 级并有提示；▶ 跳视频页；无报错。
6. W1D1 选中两行，`Cmd+D` 三次 → W2、W3、W4 的 D1 各多出这两行；改 W1 的数字，W2–W4 不变；一次 `Cmd+Z` 撤掉最近一次填充。拖填充柄从 W1D2 拉到 W4 效果相同。
7. 整天填充到非空目标天先确认；目标天已打卡动作保留；超出计划结束的周跳过。
8. 新建计划：选开始日期、4 周、周一/三/五/六 → 生成 4×4 空骨架，列头显示星期，各格日期正确。改列头 D2 为周四 → 各周未打卡的 D2 日期改为周四，已打卡的不动。
9. 存量计划回归：用至少 6 份夹具（12 周导入计划、已发布带打卡、带学员自加、后移过、每周练数不一、星期不规律）打开，所有动作、数字、实际值、日期与改动前逐项一致；不编辑直接离开不产生任何保存请求。
10. §7 能力清单逐项可用（UI 卡里展开成逐条走查）。
11. 顶栏只剩 §6 列出的元素；左上角与标签页是 app 图标；周期化条、周标签行、选中条、公式栏不再出现。
12. 中英文两套文案齐全。
13. `npm test` 全量、`npx tsc --noEmit`、`npm run build` 通过。
