# 011 · 卡 A — 主骨架、编辑态、积木复制、Dx 日期

先读仓根 `CONTEXT.md` 和 `CLAUDE.md`，再完整读 `specs/011-block-editor/SPEC.md`（含文末「屏幕稿（定稿，转写）」）。SPEC 是唯一验收口径，实装方不得自定验收范围。

## 目标
把计划编辑器主区改成「周按行 × Dx 按列」的 block 网格：扫视态是积木速记，点格子原位展开编辑，复制靠拖右下角和框选积木 ⌘C/⌘V；Dx 有星期规律；存量计划零丢失、现有能力全保住。

## 范围（本卡做）
- SPEC §1 主骨架（含窄行头、悬停容量、列头 Dx·星期·标题、积木样式、1440×900 一屏 4×4）。
- SPEC §2 编辑态全部（原位展开向右盖住同周其余列、行高按内容撑开不裁切、编辑卡只有标题与 Esc 收起、每行积木 + 备注框、底部手势提示、右键菜单三项兜底）。
- SPEC §4 复制全部（填充柄拖动、积木单选 / 加选 / 框选、⌘C/⌘V 行与整格、Delete、锁定保留、越界跳过、缺天新建、一步撤销）。
- SPEC §5 Dx 与日期在**编辑器网格里**的部分：列头星期显示、点列头改星期（只动未打卡日）、单格改日期、后移照常、存量不规律计划的显示规则。
- 去掉网格周边的旧控件：周期化条（MESOCYCLE）、周标签行与翻周、选中条（SELECTED）、公式栏、「加一周」按钮。
- SPEC §7 存量与功能保全中属于编辑器网格的全部能力。
- 本卡涉及的新界面一律按「屏幕稿 · 通用视觉」配色：不用橙 / 金，选中与焦点深色，高亮淡黄。
