## 0. 为什么

教练写计划时要一边看学员上周的视频一边改下周的数字。现在视频在「反馈工作区」，计划在「计划编排」，来回切；而且计划上看不出哪些动作有视频、看没看过。

## 术语（写入 `CONTEXT.md`）

- **待看视频**：学员已上传、教练还没看过的训练视频。「已看」沿用现状：一段视频播放进度过半即标已看（现 `VideosPage` 的 `viewed_at` 规则，学员端「教练已看」依赖它）。（2026-10-19 收货时更正：grill 第 10 题写的「现状 = 打开即已看」是 Claude 查错了，David 选的是「维持现状」，故按真实现状。）
- **视频标记**：积木上表示这个动作有视频的小标记，两种状态：待看 / 已看。
- **反馈模式**：历史栏的第二种形态，栏内放待看列表、打点列表和回复；视频在 011 的竖屏大窗里播放。与「历史模式」（spec 011 的逐级收窄）互斥。

## 1. 导航变化

- 原反馈工作区里的能力全部搬家，**不丢**：
  | 原位置 | 新位置 |
  |---|---|
  | 视频列表 + 视频工作台（播放 / 倍速 / 逐帧 / 打点 / 画线 / 快捷回复 / 发送反馈） | 计划编排 · 历史栏「反馈模式」（§3） |
  | 与学员的对话 | 计划编排 · 右下角聊天浮窗（§4） |
  | 跨学员看谁有未读 / 待看 | 总览两列（§5） |
- 老地址 / 老书签进入反馈工作区时，落到计划编排同一学员，不报错。

## 2. 积木上的视频标记

- 粒度 = **动作**（一块积木）。一个计划动作下任一组有视频，就在速记末尾、完成标记之后显示视频标记。
- 两种状态：**待看**（该动作至少一段视频未看）与 **已看**（该动作所有视频都已看）。待看要一眼跳出来，已看要安静；具体样式以屏幕稿为准，遵守 011 §6「编辑器不用橙色，淡黄可用」。
- **练了没传视频**：不另加标记，和现在的已打卡显示完全一样。
- 标记悬停提示：「3 段视频 · 1 段待看」。
- 编辑态里同样显示在对应动作行上；学员自加动作（只读行）在编辑态行上显示，**扫视态里落在那一格右上角**（扫视态没有自加动作的积木）。
- 对应关系：视频的 `plan_exercise_id` ∈ 当前打开计划的动作 → 落到该积木；`set_index` 决定第几组。
- 点击标记 = 打开反馈模式并播放该动作**第一段待看**视频（全看过则第一段）。

## 3. 反馈模式（历史栏的第二种形态）

### 3.1 进出
- 进入：点积木 / 格角上的视频标记；点总览「待看」数字跳转过来（§5）；点栏顶「待看 N」入口。
- 进入后**历史栏宽度不变**（280px，不加宽，网格不让位），栏内容换成反馈模式；视频在 **011 §3.3 的竖屏大窗**里播放（贴历史栏左侧、浮在网格上，约 405×720，按原比例），与回看历史视频是同一个窗。退出后回到原来的历史级别。（2026-10-19 David 看稿后定，取代「加宽到 420、播放器放栏内」。）
- 退出：栏顶「← 历史」或 `Esc`。Esc 顺序：焦点在回复框时先离开输入框 → 关竖屏大窗 → 退反馈模式 → 收起编辑卡（与 011「Esc 先关视频窗」一致）。关掉大窗不退反馈模式，点列表里任一条重新打开。
- 历史栏手动收起（窄条）状态下点视频标记：先展开再进反馈模式；退出后回到收起。
- 不打断编辑态：编辑卡可以继续打字，自动保存不受影响。

### 3.2 结构（细节以屏幕稿 ⑧ 为准）
- **竖屏大窗**（011 的那个窗）：标题行「W2 · D2 · 竞技卧推 · 第 1 组 122.5×2 @8.5」+ 「3 / 6」+「Esc ×」；视频；进度条上显示打点刻度；控制条：倍速 0.25/0.5/1/2、逐帧、**画线**、**＋打点**、时间。画线与打点直接在大窗上做，复用视频页组件与接口。
- **历史栏（280px）自上而下**：
  1. 栏顶：「← 历史」·「待看 N」·「含已看」开关
  2. **待看列表**（§3.3）
  3. 当前视频的打点列表（时间 · 级别 · 文字）
  4. 回复区（栏底）：快捷回复 ⌥1–5、输入框、「发送反馈 ⌘↵」，沿用现工作台行为与接口

### 3.3 待看列表：对得上计划
- 按**计划顺序**排（W 升序 → Dx 升序 → 动作在当天的顺序 → 组序），每条写成「W2 · D3 · 相扑硬拉 · 第 3 组」。
- 悬停 / 选中一条 → 网格上对应积木同步高亮（淡黄底），必要时滚动到可见；反过来，在网格上点积木标记，列表里对应条目选中。
- 列表默认只列待看；带一个「含已看」开关，打开后已看的按同一顺序灰显插回去（替代原视频页的「全部 / 已看」筛选）。
- **不在本计划**的视频（上个 block、`plan_exercise_id` 为空）：列表末尾单独一节「不在本计划」，每条写「10/12 · 相扑硬拉 · 第 2 组」，按日期倒序；点了照常播放，网格不高亮。
- 当前一段播放过半（标已看）后，该条从待看移出，积木标记随之变化（该动作全看完 → 变已看）。`← / →` 在列表里切上一段 / 下一段（焦点在栏内时）。

### 3.4 数据
- 当前学员的视频列表沿用现有接口（与原反馈工作区同一份数据），无新接口。
- 已看沿用现 `markVideoViewed` 逻辑：播放进度过半时发一次（同一段只发一次）；历史回看的大窗同样适用。
- 视频列表加载失败：标记不显示，栏顶「待看」处给重试，不影响编辑。

### 3.5 切换学员 / 计划
- 切学员：退出反馈模式，回到新学员的历史栏第 0 级。
- 切到同一学员的另一份计划：反馈模式保持，列表按新计划重排（原计划的视频进「不在本计划」）。

### 3.6 与 011 竖屏视频窗的关系
- 011 §3.3 的行为**不变**：历史记录里的 ▶ 照旧弹竖屏大窗，历史栏保持历史模式。大窗只有一个组件：反馈模式与回看共用，回看时控制条同样有画线 / 打点。
- 旧后端降级（011 §3.4）照旧。

## 4. 聊天浮窗（右下角）

- 只在计划编排出现，对象 = 当前学员。
- 收起态：右下角一个圆形按钮，带当前学员未读数；展开态：约 360×520 的对话窗，内容与原对话页一致（文字、视频胶囊、发送）。
- 对话里的视频胶囊点击 → 进入反馈模式播放那一段。
- 不遮挡关键操作：竖屏大窗打开时，聊天按钮 / 浮窗移到大窗左侧，不与大窗、历史栏重叠；编辑卡滚到浮窗下方时可收起浮窗。
- 展开 / 收起状态记在本机。切学员时浮窗保持展开 / 收起状态，内容换成新学员。
- 学员还没有会话时，沿用原「开始对话」行为。

## 5. 总览加两列

- 总览学员表新增两列：**待看视频**（该学员待看视频数）、**未读消息**（该学员未读数）。为 0 显示「—」。原学员名旁的未读圆点去掉（被列替代）。
- 点「待看视频」数字 → 跳计划编排该学员，直接进反馈模式并播放**第一段待看**（按 §3.3 顺序，计划内优先）。
- 点「未读消息」数字 → 跳计划编排该学员并展开聊天浮窗。
- 两列可排序（降序把要处理的学员顶上来）。

中英双语（spec 008 i18n），新增文案与删除的反馈工作区文案同步清理；全仓 grep「反馈工作区」/ `feedback` 导航键，旧词残留为验收项。

## 7. 「显示实际」开关（扫视态看学员实际完成）

- 顶栏右上角、保存状态左边一个开关「显示实际」，**默认关**，开关状态记在本机（按教练，不按计划）。只读计划同样有。
- **关**：扫视态与今天完全一致。
- **开**：
  - 已打卡的动作：积木上的速记**换成实际速记**——写法与处方速记完全同一套规则（`组×次 @强度 · 重量`，逐组不同时用 `/` 连接，与现 `shorthand` 一致），数据取学员记录：组 = 实际记录的组数（含额外组），次 / 强度 / 重量取各组实际值；没填 RPE 的组强度位写 `—`。字色深色，末尾仍是 ✓ 与视频标记。
  - 没打卡的动作（未来的天、当天没练的动作）：处方速记**变灰**，一眼分出哪些是实际、哪些还是计划。
  - 悬停一块显示实际的积木：提示框显示原处方速记（「处方 4×3 @8 · 125」）。
  - **学员自加动作**作为只读积木排在当天最后，名字后带灰色小字「自加」，速记同样是实际速记；不可选中、不可复制、不进框选。它的视频标记落在这块积木上（开关关闭时仍在格子右上角，§2）。
  - 格子高度随内容变化，周行撑高时整页上下滚动（同 011 规则，不裁切）。
- 编辑态不受开关影响（实际行一直显示，spec 010 不变）。
- 开关不改任何数据、不进快照、不影响复制 / 填充：复制粘贴的永远是处方，不是实际值。

## 验收清单

1. 一级导航不再有「反馈工作区」；命令面板、快捷键提示、`⌘K` 搜不到它；老地址落到计划编排同一学员。
2. 计划编排导航项上的计数 = 全部学员未读 + 待看视频（原反馈工作区徽标口径）。
3. 有待看视频的动作，积木显示「待看」标记；全看完的显示「已看」；练了没传的与现已打卡显示一致；没练的无标记。
4. 学员自加动作的视频：扫视态在格子右上角、编辑态在只读行上显示标记。
5. 点标记 → 历史栏（宽度不变）进入反馈模式，竖屏大窗播放该动作第一段待看；网格不跳页、不让位，编辑卡不关。
6. 待看列表按 W → Dx → 动作 → 组顺序；每条「W · Dx · 动作 · 第 N 组」；悬停 / 选中与积木双向高亮。
7. 「不在本计划」一节列出上个 block 与未关联计划的视频，可播放。
8. 播放过半即已看：列表移出、标记即时变化、刷新后保持；同一段只请求一次已看；只打开不播放不算已看。
9. 打点、画线、倍速、逐帧、快捷回复、⌘↵ 发送反馈在反馈模式里全部可用，结果与原工作台一致（学员端收到同样的反馈）。
10. Esc 顺序：输入框 → 竖屏大窗 → 反馈模式 → 编辑卡；「← 历史」退出后回到原历史级别。
11. 历史记录里的 ▶ 照旧弹同一个竖屏大窗（011 行为不变），回看时也能画线 / 打点。
12. 右下角聊天浮窗：未读数、展开 / 收起记忆、切学员换内容、视频胶囊进反馈模式。
13. 总览两列数字正确，点「待看」直达第一段待看、点「未读」展开浮窗；原名字旁未读圆点去掉；两列可排序。
14. 视频接口失败时编辑器照常可用，栏顶给重试。
15. 1440×900、反馈模式打开时，历史栏、竖屏大窗、聊天按钮互不重叠，网格宽度不变，无文字叠压；中英两种语言都检查。
16. 存量计划、带历史视频的老学员打开计划第一屏正常，不改任何计划数据。
17. 「显示实际」默认关，关时扫视态与改动前一致；开关状态刷新后保持。
18. 开：已打卡动作显示实际速记（逐组不同用 `/`，含额外组），未打卡的处方速记变灰；悬停显示原处方。
19. 开：自加动作以只读积木出现在当天末尾，带「自加」，不可选中 / 复制；其视频标记跟着落到积木上。
20. 开着开关时 ⌘C / ⌘V、拖右下角复制的仍是处方；编辑态显示不变。
