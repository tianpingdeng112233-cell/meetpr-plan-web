## 0. 为什么

教练给多个学员排相近的训练，想把 A 的一天或一周直接搬到 B。现在一换学员，复制的内容就没了。

## 现状事实（已核实，main@fddc817）

- 复制（⌘C / 右键「复制」）有三种：选中的动作、单天、连续多天。内容存在 `PlanEditor` 组件内的 ref（`rowClipboardRef` / `dayClipboardRef` / `daysClipboardRef`），完整保留行数据（含 `opaqueSets`：App 端设的逐组休息、组备注）。同时把一份文本写进系统剪贴板，供贴到 Excel。
- `PlanWorkspace.tsx` 以 `key={planId || empty-${studentId}}` 挂载编辑器：**换学员或换计划都会重新挂载，内部剪贴板清空**。
- 清空后粘贴会退回读系统剪贴板文本，再解析成动作行（多天结构丢失、逐组设置丢失）。线上站点是 http 明文地址（非安全上下文），浏览器不提供 `navigator.clipboard`，**线上跨学员 / 跨计划粘贴完全不通**。
- 粘贴规则（现有，不变）：锁定天（含已打卡动作）只替换未锁定行；覆盖非空天前 `confirm`；多天按相对日偏移落位，超出计划范围的天跳过并在状态栏报数；一次粘贴一次 ⌘Z。
- 教练自建动作属于教练本人，同一教练名下的学员之间 id 通用。

## 1. 行为

- 复制手势、粘贴手势、粘贴规则全部不变。
- 复制的内容在**当前浏览器标签页**内保持有效：换学员、换计划、刷新页面后仍可粘贴，直到下一次复制覆盖它。新开的标签页没有。
- 动作、单天、连续多天三种都可跨学员、跨计划粘贴，内容与同计划内粘贴完全一致（含逐组设置）。
- 重量、强度、组次、备注原样带过去；不做换算、不清空、不加额外提示（状态栏沿用现有粘贴文案）。
- 不能粘贴的目标：只读编辑器（历史计划、已解绑学员）、没有计划的学员（与现状一致：先建计划）。
- 目标计划已发布：粘贴只改本地，点「更新计划」才下发（现有逻辑）。

## 验收清单

1. 学员 A 复制一个动作 → 换到学员 B → 选中一天 ⌘V：动作出现在 B 该天的正确分区，含原学员的重量、强度、备注。
2. 同上，单天复制（右键「复制」也验一次）→ 粘到 B 的空天 / 非空天（出现覆盖确认）。
3. 连续多天（如整周）复制 → 粘到 B：按相对日落位，超出计划范围的天跳过且状态栏报数。
4. 同一学员两份计划之间：1–3 各验一条。
5. 带 App 逐组设置（「≠」行）的动作跨学员粘贴后保存，B 的计划树里逐组休息 / 组备注与源一致。
6. 复制后刷新页面，仍能粘贴；新开标签页里 ⌘V 不会贴出这份内容。
7. 粘到锁定天只替换未锁定行；粘贴后一次 ⌘Z 全部撤销。
8. 目标为已解绑学员或历史计划：不能粘贴。
9. 目标为已发布计划：粘贴后学员端不变，点「更新计划」后两端 App 看到新内容。
10. 带历史的老教练账号：打开编辑器第一屏正常；同计划内复制粘贴行为与改前一致；复制到 Excel 的文本格式不变。
11. 本地全量测试 + `tsc --noEmit` + build 全绿；Opus 浏览器亲验以上各项。
