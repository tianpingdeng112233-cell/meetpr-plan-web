# 设计 Brief · MeetPR 教练计划网页编写端

## 一句话
为力量举教练做一个**「Excel 加强版」的网页计划编辑器**：教练像在 Excel 里一样把整套训练计划一条往下写完，但产出是结构化数据，直接进 MeetPR App，学员照计划逐组打卡。请按这份 brief 出高保真 UI。

## 用户与场景
- 用户：力量举教练（成年、专业、效率优先）。现状是用 Excel 写计划，习惯紧凑、信息密度高、键盘流。
- 场景：**桌面/笔记本浏览器**（不是手机）。一次给一个学员写 8–12 周计划，反复复制周、微调重量。
- 语言：**简体中文 UI**。
- 风格基调：像专业表格工具一样**密、快、可扫视**，但比 Excel 更克制、更有呼吸感。不要花哨、不要圆润卡通；要冷静、精确、可信赖。

## 必须对齐的品牌
本网页是 MeetPR 生态的一部分，视觉必须和 MeetPR App **同源**：
- 复用 MeetPR DesignKit 的设计令牌（色板 / 字阶 / 间距 / 圆角 / 阴影）。设计交付包：`api.anthropic.com/v1/design/h/C9P9KAyVOHXwxNtSv19Vuw`（16 屏 iOS kit + tokens，与 App DesignSystem 1:1）。
- 网页是 App 的"第二个编写入口"，气质要让教练一眼认出"这就是 MeetPR"。

## 交互 / 布局规格（已冻结，请照此设计，附带可交互 HTML 原型为准）
**整体 = 一张连续往下滚的长表（像 Excel 一条长 sheet）：**
1. **顶栏**：学员选择 ▾ · 计划名 ▾ · 草稿/已存状态 · 「发布给学员」主按钮。
2. **工具栏（吸顶）**：计划名 · 周期（如 12 周）· **当前第 N 周**指示（随滚动更新）· 缩放读数 · 跳到周 ▾。
3. **主区 = 所有周完整铺开、竖向堆叠**，上下滚看前后周（不折叠、不分页）。每周一条横带：
   - 周带顶部有「第 N 周」标签。
   - 周内 **7 天同排一屏**（周一…周日横向铺满，不横向滚动）。
   - **休息日 = 窄列**（竖排"休息"），把宽度让给训练日。
4. **每个训练日 = 一个五列小表**：`动作 ｜ 组 ｜ 次 ｜ 强度 ｜ 备注`。
   - 动作：可输入、边打边联想动作库；命中库显示 `✓` 角标，自建显示「自定义」角标，纯文字辅助显示「备注」角标。
   - 组 / 次：窄列，数字。
   - 强度：见下节（逐组小框）。
   - 备注：tempo（如 310）、自由文本等。

**强度列（核心，逐组直填）：**
- 每行带一个**模式 chip**：`kg`（默认）或 `RPE`。chip 决定这行强度的含义。
- **组数 = N → 强度列展开成 N 个小输入框**，每组直填一个值：重量 `80 85 90 90`、或 RPE `6 7 8 8`。重量和 RPE 都是逐组、所见即所得。
- 无强度的辅助行（如"徒手 塑形"）：强度留空，组/次和文字落在备注，整行更弱化。
- 请设计这些状态：空框、填值、N 个框排布（含 5–6 组时不挤）、kg 态、RPE 态、模式切换。

**选中某天 → 上下文动作条（蓝条，吸在顶部）：**
- `复制上周计划到本周`（把上一周整套灌进选中日所在的这周）· `加动作` · `设为休息` · `清空本日` · `✕ 取消选择`。
- 第 1 周时「复制上周」置灰禁用；目标周非空时复制要有确认态。
- 请设计：未选中态、选中某天的高亮态、动作条出现态。

**类 Excel 的两个手感（请在视觉上体现可操作性）：**
- **列宽可拖、按星期几独立**：每列边界有一根贯穿整列全高的分隔条，鼠标移上去变 ↔。拖"周二强度"→ 所有周的周二强度一起变宽（纵向同列），但不影响周一/周三。需要一个清晰但低调的"可拖"视觉提示（hover 时列边界高亮）。
- **缩放 + 平移**：Ctrl+滚轮 / 触控板捏合放大缩小（整张表等比，下限=一周刚好占满，上限约 2 倍）；放大后按住鼠标中键拖动平移。缩放是手势，不需要按钮，但需要一个 `缩放 100%` 的读数。

## 明确不做（V1，别设计）
- 百分比(%top) 强度模式（只做 kg / RPE）。
- 「注意事项」整页（热身/RPE 量表/营养计算器）。
- Excel 文件导入、PDF/图片导出、跨学员模板库、多人实时协同。

## 期望交付
1. **高保真主屏**：编辑态（铺了真实计划数据的一周 + 上下相邻周）。
2. **关键状态**：选中某天 + 上下文动作条；强度 kg 态 / RPE 态 / 空态；动作联想下拉；自定义/备注角标；草稿 vs 已发布；列宽拖拽 hover 提示；放大态。
3. **休息日窄列**、顶栏 / 工具栏 / 当前周指示。
4. **设计令牌映射**：用到的颜色/字阶/间距对到 MeetPR DesignKit 令牌（方便前端 1:1 还原）。
5. 桌面优先；说明在窄屏/笔记本下的取舍即可（V1 不要求手机）。
