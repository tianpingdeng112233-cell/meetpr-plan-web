# 012 · 卡 E — 热修：列头「只在 W…」叠字、积木里动作名被挤没

先读仓根 `CONTEXT.md`、`CLAUDE.md`，`specs/012-insert-delete-training-day/SPEC.md` §1 与 `specs/011-block-editor/SPEC.md` §1。分支 `fix/012-headers-bricks`（基于 main 2418cca，012 已上线 staging）。

## 现象（David 2026-10-19 线上，学员吕子豪 12 周计划「01-12」，W1 起 1/12）
1. 列头几乎每列都写「周一 · 只在 W1、W2、W3、W4、W5、W8、W9、W10、W11、W12」这样的长串，文字不截断，相邻列头叠在一起像乱码。这份计划个别周少练一天（W6、W7 等），在本浏览器里没有存过星期规律。
2. 积木里逐组的速记很长（如 `4×3 · 92.5/82.5/82.5/82.5`、`4×12 @6/7/8/8`），动作名被挤成「宽握距罗马尼亚…」「弹..」「竞…」，看不出是什么动作。

## 疑似根因（先用测试证实再改）
1. 「只在 W…」的判定把所有不在本机星期规律里的列都当成插入列；老计划没有本机规律时，几乎每列都被这样标。列头容器也没有 `nowrap + ellipsis`。
2. 积木是单行 flex，速记不收缩，名字被压到最小。

## 要求
1. 列头：
   - 没有本机规律的计划，用数据推出的列（spec 011 的投票落列）就是规律列，只写星期。
   - 「只在 W…」只标在**出现周数不到一半**的列上，最多列出 3 周，超出写「等 N 周」（如「周四 · 只在 W2、W3、W5 等 4 周」）。
   - 列头单行，放不下省略号截断，悬停显示全文；任何宽度下列头不互相重叠。
2. 积木：
   - 动作名优先完整显示，至少保留约 6 个汉字的宽度。
   - 名字和速记一行放不下时，积木变两行：第一行动作名（放不下才省略），第二行速记靠右（放不下才省略）。
   - 悬停积木显示「完整动作名 + 完整速记」。普通短行仍是一行 24px。
3. 不回退 011 / 012 任何行为；不改数据模型、reconcile；不用橙色。

## 测试 seam（先红后绿）
- 用接近现场的夹具：12 周、W1 起某周一、每周 4–5 练、个别周缺一天、长逐组速记。
- 写会红的用例：断言规律列列头不含「只在」，偶尔出现的列才含，且最多 3 个周号 +「等 N 周」；列头样式为 nowrap / ellipsis（按卡 A 读实际 CSS 的方式）；长名长速记的积木名字不被截成 3 个字以内（DOM 有完整名的 title，且积木进入两行样式）。
- 跑红后修到绿。

## 追加第 3 项（David 2026-10-19 线上，同一计划）
3. 插入一天后按 ⌘Z 撤销，那一天消失了，但它新开的那一列还在（D4 和 D5 之间留着一整列空白），重新载入也不消失。猜测原因：插入时把「额外星期」写进了本机设置（`blockPlanSettings`），撤销 / 删除只改了计划树，没有同步清掉这个星期；收列逻辑只在「删除这天」时跑。
   - 要求：额外列是否显示**只由当前计划树里实际存在的训练日决定**；撤销插入、重做、删除、重新载入后，没有任何训练日的非规律列一律不显示，本机残留的额外星期要被忽略或清掉。
   - 先写会红的用例：插入 → ⌘Z → 断言列数恢复；插入 → 保存 → 撤销 → 重挂载 → 断言没有空列。
