- **前置**: spec 011（block 编辑器，已上线）。本 spec 是它的后续，不改 011 的已交付行为，除下文明确替换的两点（列头内容、Dx 显示位置）。
- **级别 / 节奏**: T2（编辑器交互 + 增删训练日的保存路径）/ P1。本仓无 CI，合并闸门 = 本地全量测试 + `tsc --noEmit` + build + Opus 浏览器亲验。

## 为什么 Dx 要跟手机端一致
iOS 与安卓给训练日编号的规则是「这一周里按日期排第几个训练日」（RN `src/domain/plan/sequence.ts` 的 `dayCode`，iOS `DashboardWeekCalendar` 的 `D\(dayNumber)`）。数据里不存「加练」标记，所以网页也按同一规则编号，三端编号一致，手机端不用改。

## 1. 列头与卡片编号（替换 spec 011 §1 的列头与 Dx 显示）
- 列头只写**星期几**（如「周一」），不写 Dx，不写「深蹲日 / 卧推日」这类当天标题。只在部分周出现的列，列头写「周四 · 只在 W2」（多周时「只在 W2、W3」）。
- 每张日卡左上角显示 **「Dx · 日期」**，Dx = 这一周按日期排的第几个训练日（与手机端同规则）。所有卡片都显示。
- 编辑卡头部同样用这一周的 Dx：「W2 · D3 · 周四 10/30」。
- 列仍按星期对齐（spec 011 §5 落列规则不变）；列头的星期规律、点列头改星期的能力不变。

## 2. 插入训练日（只改这一周）
- **入口**：鼠标移到同一周两张卡之间的竖缝上出现小「＋」；该周最后一张卡右侧、第一张卡左侧也有。只读计划不出现。
- 点「＋」弹出小菜单，列出**这两天之间还空着的日期**（本周 7 天内、没有训练日的日子；首尾入口分别列出之前 / 之后的空日期）。没有空日期时「＋」不出现。
- 选一个日期 → 在该周新建这一天（空的，进入编辑态让教练直接写），只影响这一周；本周之后的训练日 Dx 自动 +1（由 §1 规则自然得出）。
- **落列**：新日期的星期对得上已有列 → 落进那一列（等于在空格里点「＋」）；对不上 → 按星期顺序新开一列，其他周这一列是空白（不显示「＋」，不算练日）。
- 已打卡的日子不受影响；新开的日子可以照常用拖右下角、⌘C/⌘V 等手势。

## 3. 删除训练日
- 选中整张日卡按 `Delete`，或右键菜单「删除这天」：这一天连同里面的动作一起删除，格子消失（变回空白或空格「＋」）。先确认（「删除 W2 · D3（周四 10/30）及其中 N 个动作？」），可 `⌘Z` 撤销。
- 只选中了几块积木时，`Delete` 仍只删这几行（spec 011 行为不变）；右键菜单保留「清空本日」（只清内容、留下这一天）。
- 这一天里**有已打卡动作**时不能删：「删除这天」置灰并提示「已有打卡记录，不能删除」。
- 某一列在所有周都没有训练日了，而且它不属于星期规律，这一列自动收掉。星期规律里的列不收，留空格「＋」。
- 本周后面的 Dx 自动 -1（由 §1 规则得出）。

## 4. 保存与发布
- 增 / 删训练日走现有保存路径（草稿自动保存；已发布计划要点「更新计划」才推给学员，和改动作一致）。不改数据模型、不改后端、不改手机端。
- 已发布计划删除一天：只允许删无打卡的天；保存后服务端这一天被删除，不留孤儿行。

## 验收清单
1. 列头只显示星期；任一卡片左上角显示「Dx · 日期」，与该周按日期的顺序一致；编辑卡头部显示同样的 Dx。
2. W2 在 D2（周三）与 D3（周五）之间插入周四：出现新列「周四 · 只在 W2」，W2 依次 D1–D5，W1 / W3 / W4 的编号不变、该列为空白。
3. 插入入口只列出空日期；两天之间没有空日子时不出现「＋」；首尾入口能在本周第一天之前、最后一天之后插入。
4. 选中整张卡按 Delete → 确认后该天消失，后面 Dx 前移；`⌘Z` 恢复；有打卡的天不能删。
5. 只选中几块积木按 Delete 仍只删这几行。
6. 插入列在所有周都删空后自动收掉；规律内的列保留。
7. 已发布计划：增删后状态显示「有改动未推送」，点「更新计划」后重新载入，结构与改后一致；不编辑直接离开不发保存请求（spec 011 验收 9 的存量夹具仍全绿）。
8. 中英文文案齐全；`npm test` 全量、`npx tsc --noEmit`、`npm run build` 通过。

## Out of Scope
- 手机端（iOS / 安卓）任何改动；后端改动。
- 把插入的一天变成整个 block 的固定练日（去「计划设置」改星期规律）。
- 跨周移动训练日（单格改日期仍只在本周内，spec 011 §5）。
