## 0. 为什么

1. **找不到**：现在唯一的反馈入口是历史栏顶的「▶ 待看 N」，字面没有「反馈」，历史栏收起时不显示；回复框要先开一段视频才出现；历史记录里的 ▶ 能播视频却不能回复。教练不知道在哪给学员写反馈。
2. **只能按组**：反馈只能挂在某一组的视频上，没有视频就没地方写，也没法对一整天的训练说话。

## 现状事实（已核实，不需要改）

- 后端 `POST /coach/feedback` 的 `plan_exercise_id`、`video_id`、`day_date` 都可为空；只带 `day_date` 即为整日反馈。`GET /students/:id/feedback` 教练可读自己给该学员的全部反馈（含 `day_date`、`plan_exercise_id`、`video_id`、`posted_at`、`read_at`）。
- 两端学员 App 的反馈列表 / 详情已经显示只带日期的反馈（标题落到日期）。iOS 教练端早已能按日期发。
- 发反馈不推送通知（现有视频反馈同样），本期不改。
- 网页 `CoachFeedbackPayload.video_id` 目前声明为必填 `string`，要放宽为可空——本仓类型，不是接口变化。

## 术语（写入 `CONTEXT.md`）

- **整日反馈**：教练对学员某个已完成训练日整体写的反馈，只挂日期，不挂动作 / 组 / 视频；同一天可多条；**不强制**。
- **已反馈（某天）**：这一天有至少一条反馈——整日反馈或按组的视频反馈都算。
- **反馈模式**：定义更新为「栏内放训练日、待看列表、打点和回复」；入口为顶栏「反馈」、历史栏「▶ 反馈 · 待看 N」，以及**点击任何视频**。

## 1. 顶栏「反馈」按钮与历史栏入口

- 计划编排顶栏常驻「反馈」按钮，位于「显示实际」开关左边：对话气泡图标 +「反馈」+ 角标。角标 = 当前学员**待看视频**数，0 时不显示角标。历史栏收起时也在；只读计划同样有。
- 关闭态：白底、1.5px 深色描边、深色字，角标深底白字。打开态（反馈模式中）：深底白字，角标白底深字。
- 点击：进入反馈模式。有待看 → 同 013 现行为播放第一段待看；没有 → 只进入反馈模式，不开大窗，训练日列表滚到最底（最近一天）。已在反馈模式时再点 = 退出（同「← 历史」）。
- 历史栏入口文案「▶ 待看 N」→「**▶ 反馈 · 待看 N**」（保留 ▶ 圆标），行为不变。
- 角标与导航项徽标（013 §1）口径不变，不算「未反馈的天」。

## 2. 点任何视频都进入反馈模式

- 规则：网页编辑器里**凡是点击视频**，都进入反馈模式、在 011 的竖屏大窗里播这段、回复框对着这段视频。覆盖：
  1. 积木 / 格角的视频标记（013 已如此）；
  2. **历史栏历史记录里的 ▶**（改 013 §3.6：原来停在历史模式、只播不能回复）；
  3. 反馈模式待看列表 / 「不在本计划」里的条目；
  4. 聊天浮窗里的视频胶囊（013 已如此）；
  5. 总览「待看视频」数字（013 已如此）。
- 历史记录里的视频不在当前计划（上个 block 等）→ 照常播放，列表里落在「不在本计划」一节并选中；在当前计划 → 待看列表对应条目选中、积木高亮（同 013 §3.3）。已看的视频即使「含已看」关着也临时显示在列表里并选中。
- 退出反馈模式后回到进入前的历史级别（同 013 §3.1）。
- 待看列表每条最前面加一个 ▶ 圆标（深底白三角），一眼看出能点播。

## 3. 反馈模式里的「训练日」

### 3.1 位置与内容
- 栏顶行改为「← 历史」·「反馈」·「含已看」（原「待看 N」标题移到待看列表的节头）。
- 栏顶下面第一节「训练日 · 选一天看当天反馈、写整体反馈」，在待看列表**上方**。
- 列**当前打开计划里学员已完成的训练日**（未完成 / 未来的天不列）。
- **排序：按训练日期升序，最近练的在最下面**。这一节最高约 192px，超出自己滚动，顶部显示「↑ 更早」；进入反馈模式时滚到最底。
- 每行三段：`W2 · D2`（等宽）· `周三 10/29`（星期 + 实际训练日期）· 状态。状态：当天已反馈 → 深色「已反馈 N」（N = 当天所有反馈条数，含按组视频反馈）；没有 → 灰字「未反馈」（不加圆点，不做待办提示）。
- 选中行：淡黄底（#FEF3C7）、`W · D` 加粗；网格上那天的格子同步高亮（淡黄底 #FFFBEB + 1.5px 深色描边），必要时滚到可见。悬停同样联动。

### 3.2 选中一天
- 回复区节头「当天反馈 · W2 · D2 周三 10/29」。
- 下面按时间升序列出**当天所有反馈**，每条一张浅灰卡：首行「时间 · 出处 · 已读 / 未读」，出处 = 「竞技卧推 第 1 组」（按组视频反馈）或「整日」；第二行反馈文字。
- 输入框占位「给 W2 · D2 的整体反馈…」，「发送反馈 ⌘↵」。发送 = `POST /coach/feedback`，`{ student_id, day_date: 该天实际训练日期, plan_exercise_id: null, video_id: null, text }`。成功后清空输入、追加到列表、状态更新；失败保留输入并提示重试。整日反馈可写可不写。
- 选中训练日 ↔ 播放视频互斥：选中训练日时关闭大窗；点任一视频则取消训练日选中，回复区回到「回复这段视频 · W2 · D2 竞技卧推 第 1 组」+ 打点列表（013 行为）。
- `day_date` 取学员**实际训练的日期**（学员记录的日期），不是推荐日期。不能编辑、删除已发反馈。

### 3.3 数据
- 反馈读取用 `GET /students/:id/feedback`。按天归属：`day_date` 优先；`day_date` 为空但 `plan_exercise_id` 属于当前计划 → 归到该动作所在的训练日；都对不上 → 不计入任何一天。出处：`video_id` 或 `plan_exercise_id` 非空 = 按组（显示动作名 + 组号，组号取视频的 `set_index`，取不到只写动作名）；都为空 = 整日。
- 读取失败：训练日列表照常显示（不带状态），节头给重试；不影响编辑和视频反馈。发出视频反馈后同样刷新当天状态。

## 4. 网格上的「已反馈」标记

- 当天已反馈 → 那天格子头部（`D2 · 10/22` 同一行右侧，自加标记左边）显示一个小签：浅灰底 #F9FAFB、1px #E5E7EB 描边、对话气泡小图标 +「已反馈」，多于 1 条时后面跟条数（「已反馈 2」）。按周排、按天排、扫视态、编辑态都显示。
- 悬停：深色提示框（约 268px 宽）标题「W1 · D3 周五 · 反馈 2 条 · 点开在反馈栏查看」，下面逐条「时间 · 出处」+ 文字（过长截断）。
- 点击 = 进入反馈模式并选中这一天。
- 样式安静，不和视频标记抢眼；遵守 011 §6「编辑器不用橙色，淡黄可用」。

## 5. 切换学员 / 计划

- 沿用 013 §3.5：切学员退出反馈模式；切同一学员另一份计划时反馈模式保持，训练日列表换成新计划的已完成天。

## 6. 文案

简中 / 英 / 繁（spec 008、018）三套齐。全仓 grep 旧文案（「▶ 待看」作入口名、`pendingVideos` 用作入口的位置）残留为验收项。

## 验收清单

1. 计划编排顶栏常驻「反馈」按钮（「显示实际」左边），历史栏收起时仍可见；角标 = 当前学员待看视频数，0 时无角标；打开态反色。
2. 点「反馈」：有待看 → 进入反馈模式并播放第一段待看；无待看 → 进入反馈模式、不开大窗、训练日列表在最底。再点退出。
3. 历史栏入口为「▶ 反馈 · 待看 N」，旧文案无残留。
4. 点历史记录里的 ▶ → 进入反馈模式播这段，回复框可直接回复；不在本计划的视频落「不在本计划」并选中；退出后回到原历史级别。积木标记、待看列表、聊天胶囊、总览数字照旧进入反馈模式。
5. 待看列表每条前有 ▶ 圆标。
6. 训练日一节在待看列表上方，只列本计划已完成的天，日期升序、最近在最下；每行带星期；已反馈显示「已反馈 N」（含按组视频反馈），未反馈灰字。
7. 悬停 / 选中训练日与网格那天格子双向高亮（两种排版）。
8. 选中训练日 → 列出当天所有反馈（出处正确）→ 不开视频就能写；⌘↵ 发出的请求体 `plan_exercise_id`、`video_id` 为 null、`day_date` 为实际日期；学员端反馈列表出现这条；网页列表追加、状态更新；刷新后仍在。
9. 选中训练日时大窗关闭；点视频后回复区回到视频反馈，013 的视频反馈结果不变。
10. 网格上已反馈的天显示「已反馈 / 已反馈 N」，悬停看内容，点击进入反馈模式选中该天。
11. 反馈读取失败时训练日列表仍在、节头可重试，编辑与视频反馈不受影响；发送失败输入不丢。
12. 存量学员（带历史视频反馈、没有整日反馈）打开计划第一屏正常：有视频反馈的天显示已反馈；013 其余验收项不回退。
13. 1440×900 下顶栏按钮、历史栏、竖屏大窗、聊天浮窗互不重叠；简中 / 英 / 繁三种语言检查无叠压。

## Out of Scope

- 不依赖视频的「按动作」文字反馈。
- 学员 App 训练页里显示当天反馈（需要后端与两端，另立）。
- 编辑 / 删除已发反馈；反馈推送通知。
- 给未完成 / 未来的天写反馈（练前叮嘱用动作备注）。
- 角标计入「未反馈的天」；把整日反馈做成必填 / 待办。
- 手机端教练的任何改动。
