## 目标

教练打开一份周期时，若学员有上一周期，就在当前周期 W1 之前带出它的最后 2 周，整区只读，可展开、折叠、复制到当前周期。

## 范围与做法

1. **选出上一周期**：新增一个导出的纯函数，输入学员计划列表与当前计划，返回上一周期或空。规则见 SPEC 行为 1（非草稿、开始日更早、取最近；开始日相同取 `published_at` 更晚；草稿不算）。
2. **读取**：`PlanWorkspace` 在当前周期加载完成后读取上一周期（一次 `getPlan`），沿用现有的 generation 防串台做法；读取不阻塞当前周期的首屏与编辑。失败时上一周期区显示一条可重试的错误条，当前周期照常可用。
3. **渲染**：上一周期作为独立的只读数据传给 `PlanEditor` / `BlockGrid`，复用现有的周、日、动作块渲染，按周排在 W1 上方、按天排在 W1 左侧。它**不得进入**当前周期的 `weeks` 状态、撤销栈、自动保存、快照、reconcile、待核对行计数、容量汇总。
4. **标题条与文案**（屏幕稿 `design/Main.dc.html`、`design/ByDay.dc.html`、`design/States.dc.html` 的 A、C、D 三态；本卡标题条固定带「只读 · 可以查看和复制」）：
   - 上一周期区：灰底整区；深灰「上一周期」标签 + 周期名 +「<开始日> 起 · N 周 · <状态>」；右侧「显示 W4–W5（最后 2 周）」「↑ 再往前 1 周」「展开整份」「折叠」。全部展开后文案为「显示 整份 W1–W5」，前两个按钮不出现。折叠后信息加「· 已折叠」，右侧只留「展开」。按天排时「再往前」的箭头朝左。
   - 当前周期区顶：黑色「当前周期」标签 + 周期名 + 同格式信息，无底色。仅在存在上一周期时显示这一行。
   - 顶栏周期下拉的标签「计划」改为「周期」。
   - 三套语言都要有：简体如上；繁体「上一週期 / 當前週期 / 週期」，其余照简体转写；英文用 Previous block / Current block / Block。
   - 颜色只用编辑器现有 CSS 变量，不新增色值；日卡片与动作块样式不变灰、不降透明度。
5. **显示范围**：默认最后 2 周（不足则全部）；「再往前 1 周」每次加一周；折叠状态按教练存本机（`localStorage`），显示周数不存。
6. **显示实际**：上一周期区跟随顶栏现有开关。
7. **周编号与当前周标记**：上一周期沿用自己的 W 编号和推荐日期；「当前周 / 本周」标记落在实际包含今天的那一周。
8. **复制**：上一周期区可以选中动作块、整天并 ⌘C，粘贴到当前周期走现有剪贴板路径。上一周期区不接受粘贴、拖放、跨周填充、右键修改类菜单；当前周期的拖动与跨周填充不得落进上一周期区。

## 约束

- 上一周期区不发任何写请求；每次打开周期至多多一次读请求（后端全局限流 100 req/min）。
- 没有上一周期时，DOM 与请求必须与现状一致（不出现「当前周期」行）。
- 不改「新建计划」对话框与入口，不改历史栏，不改导航。
- 守仓内 lint 与格式配置（`npm run lint`），以仓内配置为准。

## 测试 seam（先红后绿，只在这三处加测试）

1. 上面第 1 条的纯函数：表驱动（无上一份 / 只有草稿 / 日期空档 / 开始日相同 / 多份取最近 / 当前是最早一份）。
2. `PlanWorkspace` 在 HTTP 边界的渲染测试（照 `src/features/workspace/PlanWorkspace.test.tsx` 现有做法）：带出、读取失败与重试、请求次数、无上一周期时不变。
3. `PlanEditor` 交互测试（照 `cross-mount-paste-ui.test.tsx` / `by-day-layout-ui.test.tsx` / `block-drag-ui.test.tsx` 现有做法）：展开折叠与文案、两种排版、复制粘贴、拖动与跨周填充不越界、上一周期不进待核对计数。
