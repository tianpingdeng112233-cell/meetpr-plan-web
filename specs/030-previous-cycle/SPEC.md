# 030 — 编辑器里带出上一周期

- **状态**: Draft。2026-11-16 David「确认」共识并「定稿」屏幕稿；未派卡。
- **级别 / 节奏**: T3（编辑器一屏挂两份计划的保存状态）/ P1。只动本仓，后端与学员端不动。
- **来源**: 2026-11-16 教练反馈——新建计划后编辑器只显示这一份，以前周期要从顶部下拉切换才看得到，排新周期时无法对照。
- **先读**: 仓根 `CONTEXT.md`（「周期（Block）」「上一周期」「延长」「后移」）。

## 现状事实（已核实，origin/main@fa0ff54）

- 编辑器一次只挂一份计划：`PlanWorkspace` 持有 `loaded`，`PlanEditor` 以 `planId` 为 key，切换下拉即整体重挂。保存、快照、发布、撤销都按单份计划走。
- 学员的计划列表（`getStudentPlans`）已在工作区里，含每份的 `start_date / plan_weeks / status`；取某份的完整内容要再调一次 `getPlan`。
- `completed` / `paused` 的计划整份只读（`historicalReadOnly`）；含学员已打卡动作的天不可拖排；已发布或有打卡的计划改不了周数与开始日。
- 一学员可同时有多份 `published` 计划。实例：李小龙，10/19 起 5 周与 11/23 起 12 周两份都已发布。
- 后端全局限流 100 req/min；写入按天先删后建，无原子回滚。

## 行为

### 带出哪一份、显示多少

1. 打开任意一份周期时，若该学员存在**上一周期**（同一学员、开始日早于当前这份、离它最近的一份非草稿计划；两份之间有日期空档也算；开始日相同时取发布更晚的），就在当前周期 W1 之前带出它。不限于刚新建的草稿。
2. 没有上一周期（第一份计划，或前面只有草稿）：不显示这一区，编辑器与现在完全一样。
3. 只向前看一份：不显示下一周期，不显示上上周期，不提供手动选择对照哪一份。
4. 默认显示上一周期的最后 2 周（不足 2 周则全部）。「再往前 1 周」逐周多显示一周，「展开整份」显示全部，「折叠」只留标题条。折叠与否按教练在本机记住；显示几周不记，每次打开回到 2 周。
5. 按周排：上一周期在 W1 上方。按天排：在 W1 左侧，「再往前 1 周」的箭头朝左。
6. 上一周期显示处方还是学员实际，跟随顶栏现有的「显示实际」开关。

### 界面区分

7. 上一周期整区用灰底，区顶是标题条：深灰「上一周期」标签 + 周期名 +「开始日 起 · N 周 · 状态」。当前周期区顶同样有一行：黑色「当前周期」标签 + 周期名 + 同格式信息，无底色。
8. 上一周期里的日卡片、动作块样式与当前周期相同，不做变灰或降透明度。
9. 周编号各周期各自从 W1 起；上一周期区沿用它自己的编号和日期。「当前周 / 本周」标记落在实际包含今天的那一周，可以在上一周期区里。
10. 顶栏周期下拉的标签由「计划」改为「周期」。下拉本身的行为不变。

### 编辑

11. 上一周期区和正常编辑计划一致：改数字、加删动作、插入删除训练日、后移、历史栏，都可用，改动属于上一份计划。
12. 现有限制原样生效：`completed` / `paused` 的上一周期整份只读（标题条显示「只读 · 可以查看和复制」）；含已打卡动作的天不可拖排；已打卡或已发布的计划不能改周数与开始日；已解绑学员整屏只读。
13. 跨周期分界：只允许复制粘贴（选中动作块或整天 ⌘C，到另一周期 ⌘V，两个方向都可以，只读的上一周期只能作为复制来源）。拖动动作块或整天不能越过分界；跨周填充到本周期最后一周为止。
14. 撤销按周期各自独立：⌘Z 撤的是当前焦点所在周期的最近一步。

### 保存与更新

15. 各归各。顶栏主按钮（发布 / 更新计划）与顶栏状态文案只管当前周期。
16. 上一周期有未提交的改动时，它的标题条上显示「未更新 · 学员还看不到这些改动」和「更新上一周期」按钮；提交成功后恢复原状。提交走现有的已发布计划更新流程（含失败重试与失败弹窗）。
17. 发布或更新当前周期时，若上一周期还有未更新改动：弹确认框，标题「只发布当前周期「<名>」」，正文「上一周期「<名>」还有未更新的改动，这次不会一起提交。发布后可以在它的标题条上点「更新上一周期」。」，按钮「取消」「发布当前周期」（更新时为「更新当前周期」）。不连带提交。
18. 上一周期的未更新改动与当前周期一样受离开保护（切学员、切周期、关页面）和快照保护；刷新后能恢复。

## 屏幕稿（2026-11-16 定稿）
