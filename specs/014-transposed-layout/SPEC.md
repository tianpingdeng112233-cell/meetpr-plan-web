## 0. 为什么

有的教练习惯 Excel 式写法：每一周是一列，同一个训练日的跨周递进横着读（W1 D1 → W2 D1 → W3 D1）。现编辑器只有「行 = 周」一种排法。

## 术语（已写入 `CONTEXT.md`）

- **按周排 / 按天排**：编辑器网格的两种排版。按周排 = 现状（行 = 周、列 = 星期）；按天排 = 行 = 星期、列 = 周。只是看法不同，计划内容完全一样。
- **跨周填充**：原「向下填充」改名，两种排版通用（按天排里是往右拖）。

## 1. 按天排的骨架

```
          W1 10/20     W2 10/27     W3 11/03     W4 11/10    │ 历史栏
周一      [一天]       [一天]       [一天]       [一天]      │
周三      [一天]       …                                     │
周五                                                         │
周六                                                         │
```

- **行 = 星期**（与按周排的列一一对应：同样的星期规律、同样的落列规则、012 插入的「只在这一周」的列在这里是只在那一周有格子的一行）。行头是窄条，只写星期几（012 §1 的列头规则原样搬到行头）。
- **列 = 周**（W1…Wn，从左到右）。列头小字：周号、该周起始日期，本周标「本周」（淡黄底）。容量摘要只在悬停列头时显示（同 011 §1 的周标规则）。
- 格子 = 一天，内容与按周排完全相同：左上角「Dx · 日期」、积木、视频标记、✓、已后移、显示实际（013 §7）。
- 尺寸：1440×900、历史栏展开时，4 周一屏放下不横滚；周数多于能放下的列数时横向滚动（6 周会横滚）。行多时整页上下滚动。
- 一次只有一个格子处于编辑态（同 011）。

## 2. 切换

- 网格左上角（行头与列头交汇的空角）放一个**图标开关**，不写字；悬停提示与无障碍名用「按周排 / 按天排」，显示的是点了会切到的那一种。
- 选择记在本机浏览器（与历史栏收起状态同一种做法），**所有计划、所有学员通用**；不进计划数据、不调后端。读不到存储（隐私模式等）时按默认处理，不报错。
- **默认按周排**：没切过的教练（新老都算）看到的和现在完全一样。
- 切换时不丢任何未保存输入；正在编辑的格子切过去后仍是那一格处于编辑态（或安全收起，不丢输入）；选中状态可以清掉。
- 切换不触发保存请求、不改「有改动未推送」状态。

## 3. 按天排的编辑态

- 点格子 → 原位展开为这一天的完整编辑卡（内容与按周排的编辑卡完全一样，011 §2）。
- 编辑卡**始终从这一周的列开始往右展开**，至少占 3 个周列宽；这一行按编辑卡内容撑高，不裁切、不溢出到下一行。
- **左边的上一周始终可见**：编辑最后一两周时右边不够 3 列，网格临时加宽、横向滚动到编辑卡，不往左借位盖住前面的周。（按周排保持现状：右侧不够时往左借位，不改。）
- 同一行里被编辑卡盖住的后面几周隐藏；其他行保持速记。
- 退出、Esc 顺序（先关视频窗再收编辑卡）、自动保存、历史栏逐级收窄都与按周排一致。

## 4. 按天排里的手势（全部转 90°）

| 能力 | 按周排（现状） | 按天排 |
|---|---|---|
| 跨周填充 | 选中格子，右下角填充柄往**下**拖到某一周 | 填充柄仍在右下角，往**右**拖到某一周；目标格虚线预览、覆盖确认、锁定行跳过、一次一步撤销都不变 |
| 插入训练日（012 §2） | 同一周左右两格之间的竖缝「＋」，首尾也有 | 同一周（同一列）**上下两格之间**的横缝「＋」，该周第一格之上、最后一格之下也有；菜单内容不变 |
| 改星期规律（011 §5） | 点列头 | 点**行头** |
| 容量摘要 | 悬停行头（周） | 悬停**列头**（周） |
| 框选积木 / 多选天 / ⌘C ⌘V / Delete / 右键菜单 / 删除这天 | — | 完全不变（框跨到别的格子 = 多选天） |
| 视频标记、显示实际、反馈模式、聊天浮窗 | — | 完全不变 |

- 编辑卡出现后自动滚到可见（现为纵向 nearest，按天排要同时照顾横向）。

## 5. 改名：向下填充 → 跨周填充

- 填充柄悬停提示两种排版统一为「拖动复制到后面几周」（英文 `Drag to copy to later weeks` 已是此意，不改）。拖动预览文案「松开：填到 W…–W… · D…」不变。
- 行内 `⌘D`（把强度 / 重量逐组往下填）是另一个已上线功能，名字与行为都不动（toast「已向下填充 N 格」指的是它，不改）。

## 验收清单

1. 没切过的浏览器打开计划编排：与上线版按周排逐项一致（存量测试全绿即证明）。
2. 点左上角开关 → 行 = 星期、列 = W1…Wn；再点切回。悬停开关看到「按天排」/「按周排」提示。刷新页面、换一份计划、换一个学员后仍是上次选的排版。
3. 按天排：行头只写星期；列头周号 + 起始日期，本周淡黄；悬停列头出现容量摘要；格子左上角「Dx · 日期」与按周排同一格一致；012 插入过的「只在这一周」的日子在按天排里是一行、其他周该行留空不显示「＋」。
4. 按天排编辑 W1、W2、W3、W4 的 D1（4 周计划）：编辑卡都从本周列往右展开、至少 3 列宽；编辑 W3、W4 时 W2 / W3（上一周）仍可见，网格横向滚到编辑卡；同行其他行不受影响；Esc 收起后网格恢复原宽度。
5. 按天排跨周填充：选 W1 周一，右下角往右拖到 W3 → W2、W3 周一被填，预览、覆盖确认、锁定跳过、⌘Z 一步撤销都对。
6. 按天排插入训练日：W2 列周三与周五之间横缝「＋」→ 选周四 → 新出现一行「周四」，只有 W2 有格子；首尾「＋」可在该周第一天之前 / 最后一天之后插入；删除这天、Delete、右键菜单照常。
7. 按天排点行头可改星期规律，结果与按周排点列头一致。
8. 切换排版时正在编辑的输入不丢、不触发保存请求；已发布计划的「有改动未推送」状态不变。
9. 显示实际、视频标记、历史栏反馈模式、聊天浮窗在按天排里都正常；收货夹具含逐组重量、逐组 RPE、10 组长行、学员自加动作、已后移的天、6 周计划（横滚）。
10. 中英文文案齐全，「向下填充」字样只剩行内 ⌘D 那处；`npm test` 全量、`npx tsc --noEmit`、`npm run build` 通过。

## 测试 seam

1. `blockGridModel`（主力，先红后绿）：给出按天排的行 / 列结构（行 = 现有列定义、列 = 周），编辑卡在按天排的起止列（始终从本周起、不足时扩宽而非左借）；跨周填充目标在两种排版下由同一函数算出。
2. `PlanEditor` 组件测试（最高层）：验收 2–8 的交互断言（切换与记忆、编辑卡位置、往右拖填充、横缝插入、行头改规律、切换不丢输入不发请求）。
3. 排版偏好读写：沿用 `RAIL_MODE_KEY` 那组测试的写法（存储不可用时回默认）。
