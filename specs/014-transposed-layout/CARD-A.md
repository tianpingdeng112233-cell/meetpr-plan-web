# 014 · 卡 A — 编辑器第二种排版「按天排」

先读仓根 `CONTEXT.md`（「按周排 / 按天排」「跨周填充」两条是本卡新词）、`CLAUDE.md`，再完整读 `specs/014-transposed-layout/SPEC.md`（含文末「屏幕稿」转写），以及前置 `specs/011-block-editor/SPEC.md` §1、§2、§4、§5，`specs/012-insert-delete-training-day/SPEC.md` §1–§3。SPEC 014 是唯一验收口径。分支 `feat/014-transposed-layout`，基于 `docs/spec-014-transposed-layout`（main `f1a0ea7` + spec）。

## 为什么一张卡
全部改动集中在编辑器网格这一个模块（模型 + 网格组件 + 样式 + 文案），两种排版共用同一套模型与手势，拆开反而要两次改同一批文件。

## 目标
1. **排版偏好**（SPEC §2）：左上角两个图标按钮切换按周排 / 按天排；本机记住、所有计划通用、默认按周排、存储不可用时回默认；切换不丢输入、不发保存请求。
2. **按天排网格**（SPEC §1、屏幕稿 ⑫）：行 = 星期（复用现有列定义与落列规则，含 012 插入出来的「只在这一周」的列）、列 = 周；行头只写星期；列头周号 + 起始日期 + 本周淡黄；悬停列头出容量摘要；格子内容与按周排完全一致（Dx · 日期、积木、视频标记、显示实际、已后移）。
3. **按天排编辑态**（SPEC §3、屏幕稿 ⑬）：编辑卡从本周列往右展开、至少 3 列宽；右侧不够时网格临时加宽并横滚到编辑卡，上一周始终可见、不左借位；行头列横滚时固定；收起后恢复原宽。按周排的编辑卡规则（含左借位）一个像素都不改。
4. **按天排手势**（SPEC §4、屏幕稿 ⑭）：跨周填充往右拖（预览、覆盖确认、锁定跳过、一步撤销沿用）；插入训练日的「＋」在同一周上下两格之间的横缝及首尾；点行头改星期规律；框选 / 多选天 / ⌘C ⌘V / Delete / 右键菜单 / 删除这天不变。
5. **改名**（SPEC §5）：填充柄提示统一「拖动复制到后面几周」；行内 ⌘D 与其 toast「已向下填充 N 格」不动。
