## 1. 导航

- 左侧只剩 总览 / 计划编排 / 动作库 / 追踪；删「学员申请」tab，也删「待排队列」（它与看板的「计划快结束」标签重复）。底部状态栏去掉「待排 N」。
- 「总览」红色计数 = 申请数 + 「需要注意」段的学员数。
- 兜底：本机记住的上次页面是 `requests` 的进来落到总览；⌘K 搜「申请 / 学员申请 / 邀请」跳总览。

## 2. 总览顶部：邀请学员 + 学员申请（左右并排）

- **邀请学员**（左，始终完整展开，内容从 `/coach/welcome` 第 3 步搬来，那页本身不动）：四步流程「把邀请消息或二维码发给学员 → 学员装 App、注册账号 → 在『输入邀请码』页粘贴邀请码并提交 → 申请出现在右边，你点『接受』」；邀请码（大字）、邀请链接、二维码；按钮「复制邀请消息」（文案与 welcome 页同一函数）、「复制链接」、「下载二维码」。没有有效邀请码时沿用 welcome 页的提示文案。
- **学员申请**（右）：沿用现申请卡（展开看入驻资料、接受 / 拒绝原地完成、60 秒轮询）。没有申请时显示「暂无新申请 · 学员提交后会出现在这里」。

## 3. 看板

- 一张表分两段：**需要注意 · N** 在上，**正常 · N** 在下（正常段文字淡一档）。段头吸顶。删掉「全部 / 待排 / 需关注」筛选。
- 列（6 列）：学员（序号 + 名字 + 小字「级别 · 体重」）/ 提醒 / 4 周完成率 / 周总量 / e1RM / 距赛。删掉 RPE、待看视频、未读消息、下周计划四列（后三者并进提醒标签）。
- 「需要注意」= 有任一非灰标签；段内按最近一条提醒的时间倒序。「正常」段沿用现有序号顺序。J / K / ↵ 跨两段连续移动。
- 零学员：只有顶部；看板位置显示「接受申请后，学员会出现在这里」。

## 4. 提醒标签与跳转

| 标签 | 颜色 | 条件（口径见后端 054） | 点击去哪 | 何时消失 |
|---|---|---|---|---|
| RPE 超标 N | 红 | 实际 ≥ 目标 + 1（区间比上限），最近 7 天 | 该学员计划编排，滚到最新一条所在训练日并展开，该组浅黄高亮 | 打开该学员计划编排（`plan-viewed`） |
| 未完成 N | 黄 | 已完成训练日里处方组没做完或失败，最近 7 天 | 同上 | 同上 |
| 计划剩 N 天 / 已结束 N 天 | 黄 | 最晚的已发布计划剩 ≤3 天（或已结束 ≤14 天）且没接上 | 该学员计划编排并弹出「新建计划」，开始日期预填为当前计划结束的次日 | 发布下一份计划 |
| 完成率低 | 红 | 沿用现有 `completionRateTone === 'bad'` | 追踪页并选中该学员 | 完成率回升 |
| 留言 N | 白 | 未读聊天数 > 0 | 该学员聊天（沿用现有「未读消息」点击行为） | 读了 |
| 视频 N | 白 | 待看视频 > 0 | 该学员计划编排并播放第一段待看（沿用现有「待看视频」点击行为） | 看了 |
| 落后 N | 虚线灰 | 推荐日期已过还没练，最近 7 天 | 打开那一天并直接弹出后移面板 | 打开该学员计划编排 |

- 只有「落后」的学员留在「正常」段，不计入红色计数。
- 标签放不下时末尾显示「+N」，悬停列出全部。
- 「备赛 N 周」不再是标签，只在距赛列。

## 5. 后移按钮挪到右上角

训练日展开卡的「后移…」从底部操作提示栏挪到卡片右上角，与「Esc 收起」并排（按周排、按天排都是）。面板内容、交互、撤销不变。

## 6. 刷新、失败与上线顺序

- 提醒随现有 60 秒可见轮询刷新；从计划编排回到总览立即刷新一次。
- 提醒接口失败：看板顶部一行「提醒加载失败 · 重试」，其余标签（留言 / 视频 / 完成率低）照常。
- 后端未部署本接口（404）：RPE / 未完成 / 落后不显示，「计划剩 N 天」退回现有「下周未排」口径——网页可先于后端上线。
